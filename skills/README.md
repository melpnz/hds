# Скиллы для коллег и ИИ

Здесь лежат самостоятельные навыки агентов. Каждый занимает одну папку, содержит `SKILL.md`, версию, `CHANGELOG.md`, необходимые скрипты и `release.json` с SHA-256 файлов. Машиночитаемый каталог — [catalog.json](catalog.json). Новые скиллы будут добавляться рядом; общая версия раздела не нужна.

## Как начать

Дайте агенту ссылку на `SKILL.md` и задачу. Для выполнения нужны не только инструкция, но и соседние файлы пакета. Если навык уже установлен, используйте его; при первой установке скопируйте **всю** папку выбранного навыка в каталог skills вашего агента (путь зависит от агента и настроек). Общая папка с junction подходит для совместной работы нескольких локальных агентов. Не копируйте весь репозиторий HDS в контекст модели.

Для получения файлов можно клонировать этот репозиторий, затем проверить `node tools/check-skills.mjs` и скопировать выбранную папку. Перед установкой сверить `release.json`; используйте один commit SHA для всего пакета. В установленной папке выполнить `npm ci`, затем `npx playwright install chromium`. Для этого навыка нужен Node.js 20+; отдельные операции с Figma и авторизацией настраиваются по SKILL.md. Секреты и результаты ревью хранить вне пакета.

## Обновления

При запуске агент выполняет встроенную проверку. В первый запуск за местный календарный день она смотрит GitHub, затем использует дневной кэш. Если новой версии нет, GitHub недоступен или проверка невозможна, работа продолжается установленной версией. Если версия новее, агент сообщает версии, пересказывает changelog между ними и предлагает обновиться. Установка — только после согласия пользователя, с резервной копией и проверкой файлов. [Подробная процедура](habr-design-review/references/updates.md).

Это правило навыка и исполняемый помощник, а не глобальный фоновый процесс: проверка выполняется, когда агент действительно читает и следует SKILL.md. Она не запускается при простом открытии папки и не может принудить сторонний ИИ выполнять инструкции.
