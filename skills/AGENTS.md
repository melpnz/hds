# Публикация и использование скиллов

Каждый скилл — самостоятельный пакет `skills/<стабильное-имя>/`. Рядом могут находиться любые другие скиллы; версии, changelog и зависимости независимы. Не создавать каталоги с номером версии и не переименовывать опубликованные пути. Каталог — `catalog.json`, вход — `README.md`; читать только выбранный навык. Перед изменением его исходника прочитать собственный `AGENTS.md` и получить разрешение автора, если оно требуется.

## Авторская среда Stepan Voevodin

Источник `habr-design-review` — `D:\.agent\skills\habr-design-review`; `D:\work\guides\skills\habr-design-review` — проверяемая копия для распространения, не второй исходник. Правки делать в источнике по прямому поручению Stepan Voevodin, повысить версию и записать changelog, затем выполнить из репозитория guides:

```text
node tools/publish-skill.mjs --name habr-design-review --source D:/.agent/skills/habr-design-review
node tools/check-skills.mjs
```

Для следующего навыка использовать другое стабильное имя, отдельный источник и `publication.json`. `publish-skill.mjs` переносит разрешённые файлы и обновляет release.json/catalog.json; не копировать всю папку вручную. Скрипт не переносит bench, историю, node_modules и результаты ревью. Не редактировать manifest/catalog руками и не менять опубликованные файлы без новой версии.

Проверить изменения и инструкции, выполнить тесты изменённого навыка. Затем адресно закоммитить и опубликовать только его пакет, каталог и связанные инструкции. Не включать соседние изменения; публикация происходит в `main`. Если рабочая ветка занята или дерево грязное, использовать отдельный worktree от свежего origin/main. `git push` выполнять только в рамках поручения владельца на публикацию. Обычный запрос на ревью не разрешает менять, копировать или публиковать исходник.

Потребителям необходимы только публичные файлы из manifest. Локальное состояние ежедневной проверки обновлений и отчёты хранятся вне навыка. Установку официального обновления разрешает пользователь своей копии; самостоятельное изменение авторского кода регулирует AGENTS.md выбранного навыка.
