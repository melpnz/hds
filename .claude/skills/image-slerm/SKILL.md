# Иллюстрации Slerm для продукта

Вход текущего запуска: `$ARGUMENTS`.

Используй локальные оригиналы как источник идентичности. Основная задача —
создать тематическую картинку для конкретного блока лендинга и сохранить её как
рабочий asset, а не просто показать отдельную генерацию.

## 1. Определи роль изображения

Из контекста страницы возьми тему, эмоцию, действие, реквизит, фон, доступное
соотношение сторон и поведение на mobile/desktop. Иллюстрация поддерживает смысл
блока и не дублирует заголовок текстом внутри картинки.

## 2. Найди референсы без загрузки каталога

Запусти поиск по теме и эмоции:

```bash
node .claude/skills/image-slerm/scripts/find-reference.mjs \
  "<topic emotion action props>" --limit 5
```

Существующие оригиналы перечислены в `references/catalog.tsv`; не читай файл
целиком в prompt. Выбери один основной PNG по ближайшей композиции, лицу и
кадрированию. Второй допустим только для конкретного жеста, костюма или предмета.
Открой выбранные PNG инструментом просмотра перед генерацией.

Если сюжет значительно меняется, прочитай
[`identity-core.md`](references/identity-core.md). Большое
[`character-description.md`](references/character-description.md) используй
только для сложной коррекции после неудачного результата или при явной работе
без изображений.

Все пути разрешай относительно папки skill и передавай генератору абсолютными.

## 3. Сгенерируй

Передай сами выбранные изображения генератору. В prompt раздели роли:

```text
Image 1 is the primary identity, material, lighting and composition reference.
Preserve its one-eye anatomy, eye-to-body ratio, iris/pupil design, short
antennae, green hue, smooth 3D surface and body silhouette.
Image 2 is ONLY a reference for [gesture/costume/prop]. Do not transfer its
different anatomy, face, color, lighting or unrelated props.

Scene: [topic, action and emotion required by the landing section].
Keep: [features and composition that must stay].
Change: [only requested details].
Output: one mascot, [aspect ratio/framing], [transparent or specified background],
no text, logo or watermark. This is the same mascot, not a redesigned cyclops.
```

Для небольшого изменения редактируй ближайший оригинал. Не используй неудачную
генерацию как новый источник идентичности: основной оригинал остаётся во входах
каждой итерации.

## 4. Проверь и подключи к лендингу

Сначала сравни с основным PNG: один глаз, его устройство и размер, силуэт, усики,
зелёный цвет, материал, свет. Затем проверь сюжет, руки, реквизит, отсутствие
случайных надписей и обрезки.

Для прозрачного asset проверь реальный alpha channel; белый фон или нарисованная
шахматная сетка не считаются прозрачностью. После двух неудачных коррекций одной
ошибки используй лучший вариант и явно назови оставшееся расхождение.

Сохрани результат вне `assets/originals`, в assets текущего сайта. Не
перезаписывай оригиналы. Подключи файл в нужный блок и проверь:

- desktop и mobile кадрирование;
- отсутствие растяжения и layout shift;
- `alt` по смыслу либо пустой `alt` для декоративной картинки;
- читаемость текста рядом с иллюстрацией;
- локальный путь без зависимости от временного URL генератора.

Для серии сохрани `generation-notes.md`: задача, основной/дополнительный
референсы и их роли, итоговый prompt, результат и статус `candidate` либо
`approved`. Новый результат становится эталоном серии только после явного
одобрения пользователя.
