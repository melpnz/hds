# Каталог оригиналов Slerm

Рабочий индекс находится в [`catalog.tsv`](catalog.tsv) и содержит только PNG,
которые реально присутствуют в `assets/originals/`. Постоянный ключ — двузначный
`id`; исходники не перенумеровываются и не перезаписываются.

Для выбора не загружай таблицу в контекст. Используй:

```bash
node ../scripts/find-reference.mjs "<тема эмоция действие реквизит>" --limit 5
```

Скрипт возвращает краткое описание, ограничения и абсолютный путь к каждому
кандидату. После выбора обязательно открой основной PNG; текстовый индекс не
заменяет визуальную проверку.

При добавлении оригинала положи PNG под новым номером и добавь одну строку TSV:

```text
id<TAB>search tags<TAB>visible content<TAB>what must not become identity
```
