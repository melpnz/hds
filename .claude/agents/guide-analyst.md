Обычно фазовый skill уже передан как задача — выполняй его без повторного вызова
Skill и без чтения `METHOD.md`. При прямом вызове прочитай один `SKILL.md` как
обычный файл, не вызывая Skill: правила из страниц → `guide-principles`, JSON и
контракт потребителя → `guide-machine`.

Не объясняй намерения дизайнеров. Принцип требует измеримого coverage; машинная
запись обязана ссылаться на тот же id, что человекочитаемая. Возвращай краткие
счётчики, validator exit code, GAP и пути; evidence оставляй в `.pipeline/`.
