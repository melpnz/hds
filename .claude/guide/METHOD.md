# Маршрутизатор метода

Этот файл — короткая карта конвейера. Не загружай все документы метода заранее:
читай только перечисленные в текущем skill.

## Результат

Пакет фиксирует наблюдаемый визуальный язык продукта в двух согласованных
проекциях:

- человеку — статьи, правила, живые примеры и страницы гайда;
- модели — `machine/*.json` и `AGENTS.md`, достаточные для сборки интерфейса без
  чтения markdown.

Источники — production, Storybook, Figma и опубликованные гайды. Догадки не
маскируются под свойства продукта.

## Входы

- `/guide` — полный цикл: inventory/audit → build → review → fix при
  необходимости → автоматические гейты → страницы → принципы → machine layer.
- `/guide-spec`, `/guide-audit`, `/guide-build`, `/guide-review`, `/guide-fix`,
  `/guide-accept`, `/guide-pages`, `/guide-principles`, `/guide-machine` —
  самостоятельные фазовые входы. Каждый запускается в профильном агенте и не
  требует предварительного `/guide`.

Новый пакет начинается со spec, существующий — с audit. До инвентаризации
определи вид: интерфейс или лендинг. Смешанный продукт разделяется на два
раздела или пакета.

## Цикл и batching

Рабочая единица — пакет из 2–4 связанных элементов одного семейства с общими
источниками и зависимостями. Одиночный элемент допустим для пилота, blocker или
явного запроса. Builder обрабатывает пакет в одном контексте; независимый
reviewer проверяет тот же пакет. Параллельные агенты используются для разных
семейств, когда важнее время, чем расход токенов.

После первого полного review повторное review инкрементально: открываются
предыдущие находки, `fix-N.md`, изменённые файлы и затронутые изображения.
Полный чеклист повторяется только при изменении общей основы или когда невозможно
доказать локальность правки.

Гейты выполняет `validate-step.mjs`. Модель разбирает смысловые критерии и
ошибки скрипта, но не повторяет успешные детерминированные проверки вручную.

Полные логи сохраняй в `.pipeline/`; в сообщения возвращай exit code, краткий
итог и путь. Evidence передавай срезами через `query-evidence.mjs`, не целыми
`computed.json` и `dom.html`.
