# Шаблон спецификации компонента

Порядок разделов фиксирован — по нему написан валидатор и на него рассчитывают
читатели. **Раздел, которому нечем подтвердиться, не пишется вовсе** (кроме
«Назначение», «Разметка», «Ограничения», «Источники» — они обязательны).
Образцы: `career/components/labels/status-chip.md`, `career/components/actions/button.md`.

---

```markdown
# CanonicalName · ЛегасиИмя

| | |
|---|---|
| **Категория** | человекочитаемое имя категории |
| **Корневой класс** | `class-root` или перечисление утилит |
| **CSS** | `ui/components/<file>.css` или _только утилиты_ |
| **Живая реализация** | `showcase/components.html#anchor` |
| **Snapshot** | сколько состояний снято из скольких |

## Назначение

Одно-два предложения: что делает компонент и чем отличается от соседнего,
на который его похоже спутать. Пишется вручную.

## Анатомия

Дерево DOM из настоящего снимка, фреймворк-скоуп снят. Продовые пути к спрайтам
здесь сохраняются как есть — это протокол снятого DOM.

## Варианты

Классы исполнения и их фон, текст, рамка — из CSS.

## Размеры

Классы размеров: высота, padding, радиус, кегль — из CSS.

## Состояния

Только слова из закрытого словаря (METHOD.md §5). На каждое состояние — правило
CSS или наблюдение в runtime. Дописанные нами состояния помечаются
«новая реализация, `ui/state-contract.css`».

## Слоты · Props

Из публичного API, если он доступен: тип, значение по умолчанию, допустимые значения.

## Токены

| Переменная | Значение | Статус |

Все `var(--…)`, встречающиеся в CSS компонента, со значениями из `:root`.

## Иконки

Спрайт, символ и локальный файл в `ui/assets/`.

## Responsive

Медиазапросы и контейнерные запросы из CSS плюс брейкпоинт-префиксы в разметке.
Если их нет — так и пишется: компонент подстраивается только под ширину контейнера.

## Доступность

ARIA-атрибуты и `role`, встречающиеся в реальной разметке. Ничего не достраиваем;
если их нет — «в снятой разметке нет ARIA-атрибутов и role. Не достраиваем».

## Поведение

Что происходит при взаимодействии — по CSS, разметке и наблюдению в runtime.

## Разметка

Готовый к переносу HTML: локальные пути к ассетам, без фреймворк-атрибутов,
работает на пустой странице с одним `ui/<product>.css`.

## CSS

Текст правил компонента.

## Ограничения

Что не подтверждено и **чего конкретно не хватает**, чтобы подтвердить.

## Источники

URL страницы и селектор, node key Figma, id story, секции CSS, файлы в `evidence/`.
```
