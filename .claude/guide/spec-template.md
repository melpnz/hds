# Шаблон статьи о компоненте

Порядок разделов фиксирован: сначала «когда и как применять» (по образцу
[Контур.Гайдов](https://guides.kontur.ru/)), затем извлечённые факты. Тон и
формулировки — [`writing-style.md`](writing-style.md).

**Раздел, которому нечем подтвердиться, не пишется.** Обязательны только
«Когда использовать», «Разметка», «Ограничения», «Источники».

Образцы извлечённого слоя не подсматривай в чужом пакете: разделы и тон
заданы этим шаблоном и [`writing-style.md`](writing-style.md).

---

```markdown
# CanonicalName · ЛегасиИмя

| | |
|---|---|
| **Категория** | человекочитаемое имя категории |
| **Корневой класс** | `class-root` или перечисление утилит |
| **CSS** | `ui/components/<file>.css` или _только утилиты_ |
| **Живая реализация** | `showcase/components.html#anchor` |
| **Snapshot** | сколько состояний снято из скольких |

## Когда использовать

В каком контексте компонент уместен. Пишется призывом: «Используйте …, если …».

## Когда не использовать

Что взять вместо и почему — со ссылкой на соседний компонент, с которым его
чаще всего путают.

## Примеры

Где он живёт в продукте: страница, место на ней, ссылка, снимок.

## Как работает

Поведение: что происходит при наведении, нажатии, вводе; режимы; что срабатывает
и когда. Настоящим временем, будто уже реализовано.

## Название и текст

Как называть содержимое: форма глагола, регистр, длина, перенос, многоточие.
Пары «неправильно → правильно» примерами.

## Размер и расположение

Размеры с контекстом применения («s — в плотных таблицах»), правила ширины,
отступы от соседей.

## Управление клавиатурой

Фокус, Enter, Escape, стрелки, ловушка фокуса, порядок обхода.

## Валидация

Недопустимые состояния и что показывается пользователю.

## Анимация

Переходы, спиннер, длительности — числами.

## Внешний вид

Варианты и их цвета, фон, рамка; состояния из закрытого словаря (METHOD.md §5).
Дописанные нами состояния помечаются «новая реализация, `ui/state-contract.css`».

## Анатомия

Дерево DOM из настоящего снимка, фреймворк-скоуп снят. Продовые пути к спрайтам
здесь сохраняются как есть — это протокол снятого DOM.

## Слоты · Props

Из публичного API: тип, значение по умолчанию, допустимые значения.

## Токены

| Переменная | Значение | Статус |

Все `var(--…)` из CSS компонента со значениями из `:root`.

## Иконки

Спрайт, символ и локальный файл в `ui/assets/`.

## Responsive

Медиазапросы и контейнерные запросы плюс брейкпоинт-префиксы в разметке.
Нет — так и пишется: подстраивается только под ширину контейнера.

## Доступность

ARIA-атрибуты и `role` из реальной разметки. Ничего не достраиваем.

## Разметка

Готовый к переносу HTML: локальные пути, без фреймворк-атрибутов, работает
на пустой странице с одним `ui/<product>.css`. Этот же блок уходит в
`machine/components.json` как `markup.html` — они обязаны совпадать.

## CSS

Текст правил компонента.

## Ограничения

Что не подтверждено и **чего конкретно не хватает**, чтобы подтвердить.

## Источники

URL страницы и селектор, node key Figma, id story, секции CSS, файлы `evidence/`.
```
