# Инварианты пакета

1. **Копируемость.** Пример работает на пустой странице после подключения одного
   `ui/<product>.css`, включая локальные иконки и шрифты.
2. **Изоляция showcase.** Документационная оболочка живёт в `showcase/*.css` со
   своим префиксом и не протекает в `ui/`.
3. **Локальные assets.** Рабочие пути ведут в `ui/assets/`; production URL
   допускаются только как evidence.
4. **Токены.** Цвета, размеры, интервалы, радиусы и шрифты в component CSS идут
   через `var(--…)`. Production literal допустим с явной пометкой.
5. **Реестр сходится.** `specPath`, CSS roots и showcase anchor каждой записи
   manifest существуют.
6. **Проекции сходятся.** Markdown и `machine/*.json` используют одинаковые id и
   не противоречат друг другу.
7. **Machine layer достаточен.** По нему можно выбрать паттерн, компоненты и
   проверки без чтения markdown.
8. **Правило видно.** Доказанное правило показано рядом с живым примером и имеет
   `data-rule`/anchor, coverage и ссылку на evidence.

Детерминированную часть проверяет `validate-step.mjs`; смысловую полноту и
качество примеров оценивает reviewer.
