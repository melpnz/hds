Цвета, встречающиеся в пакете

На эти основные --color-* есть прямые ссылки var(...) в текущих CSS, HTML или JS.

Предположительно нигде не используются

Аудит текущих CSS, HTML и JS не нашёл применения этих значений вне объявления палитры. Это кандидаты на проверку, а не команда на удаление.

Предположительно используются только в Figma

Основной --color-* не вызывается, но эквивалентное значение используется через дублирующий --fig-*.
