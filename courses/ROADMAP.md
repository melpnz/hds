# Roadmap — Хабр Курсы v1.1

Актуализировано: 5 октября 2026 года.
Сводная очередь — [Courses общего roadmap](../ROADMAP.md#courses).

## Текущий статус

Используем UI Kit владельца — Courses Nuxt Kit; переход на другую frontend-
библиотеку не планируется. Опубликованная версия — **1.2.0**, гайд — **v1.1**.
Подготовлен GitHub-черновик **1.3.1** от 05.10.2026; он ещё не опубликован.
HeaderDropdown, визуальные тесты и исправления SortSheet, FilterChip, OptionList
и API фильтров SiteHeader входят в 1.2.0; guide/provider API синхронизирован.

72 прямых соответствия, 72 provider-primary, 0 hybrid и 0 отсутствующих состояний.
Все 147 provider-токенов сопоставлены без конфликтов значений.

## Решения владельца · 01.10.2026

- Рабочая палитра берётся из используемых цветов UI Kit. Генерируемый
  `machine/reports/provider-color-usage.json` различает используемые и резервные
  CSS-токены; Figma-группы больше не требуют отдельного решения перед разработкой.
  Исторические токены сохранены для совместимости.
- Visual regression расширена: 20 поверхностей/состояний × 4 ширины =
  80 сценариев и 160 эталонов (цвет + геометрия). Старые 48 эталонов сохранены.
- По следующему решению владельца выполнен production-анализ двенадцати страниц:
  семь ширин, отдельные граничные замеры, локальные reference и правила композиции.
  Figma-сверка и точные component-сборки через kit не входят в этот срез.
- Следующий этап согласован как план: сначала доработать UI Kit по выявленным
  расхождениям, затем собрать 12 страниц из его настоящих Vue/Nuxt-компонентов.
  Старые рецепты использовать как основу структуры, новые замеры — как источник
  актуальной геометрии. Само включение в план не разрешает новые exports и варианты.
- Другая frontend-библиотека не ожидается: продолжаем развивать этот UI Kit.
- Выпуск согласован и автоматизирован через ручной GitHub Actions workflow:
  проверки точного коммита тега → ZIP слоя и каталога + SHA-256 → черновик.
  Публикация остаётся ручной; инструкция — `../tools/README-courses-release.md`.

### Точка продолжения · 02.10.2026

Все 12 исследованных production-страниц собраны вне layer как живые Vue/Nuxt-композиции
из публичных компонентов Courses UI Kit. В основном гайде они стали первичными превью;
локальные production-reference сохранены второй вкладкой для сравнения. Каталог страниц
поддерживает 320 / 480 / 768 / 1024 / Auto, а статическая сборка явно prerender-ит все
двенадцать маршрутов.

Закрыто и проверено:

1. Guide/provider-контракты, токены, manifest и machine-данные синхронизированы:
   72 прямых соответствия, 147 сопоставленных токенов, 0 конфликтов.
2. Все 12 страниц проходят браузерную проверку на 320 / 480 / 768 / 1024 / 1440
   без горизонтального переполнения; интегрированный viewer проверяет обе вкладки
   и загрузку живой композиции.
3. Найденные сборкой страниц ошибки фиксированной ширины `PromoCard` и `PersonCard`
   исправлены в ките. Карусель больше не использует устаревший экземпляр Swiper при
   пересоздании; тест явно ждёт завершения смены loop-режима и стабилен в 10 повторах.
4. `typecheck`, kit checks, guide validation, consumer build, component-page tests,
   visual regression и статическая генерация прошли. Все 12 HTML-маршрутов присутствуют
   в `.output/public`.
5. Все 12 live/reference пар вручную сопоставлены на 320 / 480 / 768 / 1024 / 1440.
   Исправлены составные формы и подписи рейтинга, отзывов и промокодов, выбранная
   организация и мобильная сводка промокодов, а также композиции экспертов и редакции.
   Найденный при этом конфликт CSS у двух полей `SearchForm` исправлен в самом UI Kit
   и закрыт регрессионным browser-тестом.

### Приёмка владельцем · завершена 05.10.2026

Все 12 страниц приняты владельцем: «Каталог курсов», «Курсы по ChatGPT»,
«Образовательные организации», «Рейтинг онлайн-школ», «Школа Skillbox»,
«Отзывы об онлайн-школах», «Отзыв о курсе», «Промокоды и акции»,
«Промокоды Яндекс Практикума», «Эксперты по оценке обучения»,
«Редакция Хабра» и «Николай Ширинкин».
Замечания по шапкам, фильтрам, карточкам, таблицам, модалкам, каруселям,
контактам и отступам исправлены; общие исправления внесены в компоненты кита.
Это локальные демонстрационные фильтры без backend: связи школ с темами, типами
и целями не являются подтверждёнными production-данными.

Очередь ручной приёмки закрыта. Каталог живых страниц:
http://127.0.0.1:3002/ui/pages (требует dev-сервера на порту 3002).

05.10.2026 обновлены восемь генерируемых provider API-описаний и отчёт
использования цветов. Полная проверка гайда `npm run validate` проходит:
API, токены, совместимость, ссылки и maturity синхронизированы.
Правила сборки, решения владельца и метаданные всех 12 контрактов также
синхронизированы с итогами приёмки. Проверка согласованности включена в validate;
исходные production-замеры не изменены.

Старые шесть статических страниц не нужны в активном каталоге: актуальные
композиции заменяют каждую из них, уникальные действующие контракты отсутствуют.
Их recipes и HTML-превью уже удалены из рабочего дерева; evidence и архив v0.1
сохраняются. Подробное соответствие —
[аудит исторических страниц](docs/decisions/historical-pages-audit.md).

Осталось:

1. Пустые, loading и backend-error состояния пока не считаются сверенными: для них нет
   production evidence.
2. Предрелизный прогон завершён 05.10.2026: 223/223 E2E (включая80 визуальных
   сценариев), check/typecheck, validate гайда, интегрированный viewer и offline
   consumer проходят. Production build и static generate проверены в изолированной
   копии; все12 страниц присутствуют в готовом HTML. Проверка безопасности релиза
   и `git diff --check` проходят. Не считать этот локальный прогон проверкой будущего
   Git-тега: workflow повторяет проверки точной ревизии перед выпуском.
3. Подготовить выпуск накопленных изменений UI Kit и гайда:
   Версия 1.3.0 закоммичена и отправлена с привязкой source и аннотированным тегом.
   GitHub подтвердил production-сборку и визуальные тесты, но выявил зависимость
   валидатора от пустой папки. Исправление включено в кандидат 1.3.1; тег 1.3.0
   сохранён. Полный CI точного тега 1.3.1 успешно завершён; создан черновик
   с архивами слоя и статичного каталога и двумя SHA-256 файлами.
   [Успешный release workflow](https://github.com/melpnz/hds/actions/runs/37311322582).
   Остаётся ручная публикация черновика только по явной команде владельца,
   затем снятие `prepared-not-published` в consumer-workflow и предупреждений README.
4. Сверку с Figma проводить отдельным этапом, если владелец поставит такую задачу.

## Границы ответственности

Machine-гайд хранит назначение, поведение, доступность и композицию;
UI Kit — публичный API, разметку, токены, ассеты и визуал.
Production и Figma — evidence, не параллельная реализация.
Копии layers/courses в продуктах остаются read-only и не обновляются автоматически.
