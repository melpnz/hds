- Рабочая палитра берётся из используемых цветов UI Kit. Генерируемый
  `machine/reports/provider-color-usage.json` различает используемые и резервные

  Исторические токены сохранены для совместимости.
- Visual regression расширена: 20 поверхностей/состояний × 4 ширины =
  80 сценариев и 160 эталонов (цвет + геометрия). Старые 48 эталонов сохранены.
- По следующему решению владельца выполнен production-анализ двенадцати страниц:
  семь ширин, отдельные граничные замеры, локальные reference и правила композиции.
  Figma-сверка и точные component-сборки через kit не входят в этот срез.
- Следующий этап согласован как план: сначала доработать UI Kit по выявленным
  расхождениям, затем собрать 12 страниц из его настоящих Vue/Nuxt-компонентов.
  Старые рецепты использовать как основу структуры, новые замеры — как источник
  актуальной геометрии. Само включение в план не разрешает новые exports и варианты.
- Другая frontend-библиотека не ожидается: продолжаем развивать этот UI Kit.
- Выпуск согласован и автоматизирован через ручной GitHub Actions workflow:
  проверки точного коммита тега → ZIP слоя и каталога + SHA-256 → черновик.
  Публикация остаётся ручной; инструкция — `../tools/README-courses-release.md`.

## Новые сервисы · очередь решений после аудита 05.10.2026

Основание — аудит внешнего прототипа «Хабр Репититор» на localhost:3000:
15 экранов, исходники и сохранённые desktop/mobile-снимки. Это не новая ручная
приёмка в живом браузере и не production evidence. Приложение не изменялось.
Принятые 12 страниц Курсов остаются принятыми; очередь ниже относится к
расширению гайда для новых сценариев, а не повторному открытию их приёмки.

Без новых дизайнерских решений выполнено: актуализированы границы покрытия,
уточнено разрешение проектировать явно заказанные новые сценарии вне layer;
добавлены карта переиспользования, минимальный контракт композиции, матрица
состояний и правила проверки открытых overlay, клавиатуры и восстановления.
Процедура связана с AGENTS, машинным индексом и consumer-workflow.
Полная проверка `npm run validate` и `git diff --check` проходят; provider,
его релизные архивы, production-замеры и приложение прототипа не изменены.

Разбирать с владельцем последовательно. Правила NS-01 согласованы ниже;
NS-02: правило фильтрации и вариант редакции согласованы, прочие примеры открыты;
NS-03: порядок согласования композиции и сохранение mobile-контента приняты;
NS-04: готовые состояния Kit и согласование непокрытой композиции приняты;
Вопросы по правилам NS-01–04 закрыты; детали новых экранов согласуются внутри
их продуктовых задач, не требуют отдельной универсальной спецификации сейчас.
NS-05 проверяется при повторном запуске исходной задачи по решению владельца:
отдельную тестовую страницу не создавать. Реализация и визуальная проверка
новых вариантов не считаются завершёнными только по записи решения.

1. **NS-01 — оболочка нового сервиса внутри Курсов: правила согласованы 05.10.2026.**
   Общие шапка и футер сохраняются; примыкающий синий hero имеет единый градиент
   с шапкой. На обычных страницах используется простая шапка сайта, H1 — на
   общем белом фоне; hero возможен по ситуации, не автоматическая светлая панель.
   Новую навигацию агент предлагает вариантами и ждёт выбора пользователя,
   а не добавляет второй уровень самостоятельно. Для «Репетитора» предпочтение
   владельца — аватарка в общей шапке и dropdown разделов, не универсальный канон.
