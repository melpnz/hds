# Changelog — Хабр Курсы

## Unreleased

Пакет продолжает развиваться после стабильного релиза; новые изменения будут
добавляться в этот раздел.

- страница цветов разделяет 12 основных токенов без прямого `var(...)` и 3
  токена, встречающихся только через дублирующие Figma-алиасы; обе группы
  синхронизированы с machine-контрактом без автоматического удаления.

## v1.0 — 2026-09-21

- завершён аудит зрелости всех 88 machine-записей: устранены устаревшие
  `unknowns`, принятые Figma-контракты переведены в нормативные, итоговая
  диагностика содержит 88 `complete`, 0 `partial` и 0 `missing`;
- `DemandChart` и `PageToc` растягиваются по ширине контейнера; на desktop
  оглавление больше не сохраняет ручной перенос из узкого исходного кадра;
- `FeedbackForm` получил способ связи «Телефон», интерактивное переключение и
  success-экран с локальной Figma-иллюстрацией; на mobile изображение доходит
  до краёв карточки и обрезается её внешним радиусом;
- `Loader` получил непрерывное вращение, а ProfessionCard, PromoCard,
  ReviewCard, ArticleCard, StepCard и VacancyCard — полноширинную раскладку на
  320/480 px;
- удалён дублирующий символ `star-rounded-small`: все рейтинговые звёзды
  используют `star-rounded`, а нужный размер задаётся SVG-контейнером;
- исправлена раскладка `Modal` без изображения: при отключении media-слота grid перестраивается на три строки, поэтому прокручиваемое тело больше не вытесняет footer и обе кнопки остаются видимыми;
- Inter закреплён как единственный интерфейсный шрифт Courses во всех компонентах, страницах и живых примерах; моноширинный шрифт разрешён только для `code`, `pre`, `kbd` и `samp`, а статическая и браузерная проверки не допускают регрессий.

- `SearchForm` переведён на группу `Select XL`: поля состыкованы без gap в единую оболочку с разделителями 1 px; на mobile группа становится вертикальной, а CTA растягивается на всю ширину;
- исправлено пустое превью `RubricationBar`: production-разметка теперь показана на штатном градиентном фоне `/courses` в компактном responsive-примере с мобильной горизонтальной прокруткой;
- добавлен базовый `Modal` по Courses Figma: единый интерактивный playground для desktop/tablet/mobile, опциональных слотов, прокрутки тела и закреплённых header/footer; `PromoCodeModal` сгруппирован с ним как доменный вариант содержимого с сохранением прежнего id;

- `SortSheet` и `PriceSheet` зафиксированы как mobile-only bottom sheets: вместо responsive-превью
  на всех ширинах добавлены интерактивные сценарии 320×568 с trigger, overlay, закрытием и возвратом фокуса;
- `FilterModal` перестроен по мобильному макету Education Figma: добавлены все десять групп,
  точные локальные ассеты, фиксированные header/footer и отдельный вертикальный скролл тела;
  на 320 px действия складываются в две полноширинные кнопки с primary первой;
- исправлено пустое превью `HeaderDropdown`: закрытый SSR-snapshot заменён
  интерактивным примером `open/closed` с сохранённой production-панелью сервисов;
- исправлено пустое превью `AdSlot`: вместо неинициализированного внешним
  скриптом `.adfox-banner` показана локальная responsive-карусель из двух `AdCard`;
- исправлено превью `Section`: вложенный `RatingTable` заменён нейтральной
  анатомией секции с заголовком и областью содержимого;
- каталог viewer перестроен в четыре уровня `Основы → Элементы → Блоки → Страницы`
  без изменения существующих адресов компонентов и страниц;
- добавлены шесть наглядных foundation-страниц: цвета, типографика, отступы и
  сетка, скругления и границы, иконография, адаптивность и брейкпоинты;
- для `Avatar` и `EntityLogo` добавлены дефолтные SVG-изображения из Career и
  полные шкалы 24/32/36/40/48/56/68/100 из Courses Figma; обе заглушки используют
  единую палитру Courses `#F1F1F1` / `#D3D3D4`, пользовательская геометрия сверена с `avatar/user`;
- радиусы `EntityLogo` привязаны к размеру по `avatar/school`: 6/8/12/12/12/12/16/24 px;
- для intrinsic-примеров добавлен явный контракт presentation: компактные элементы,
  контролы, контентные и контекстные области больше не получают случайную ширину;
- исправлен расчёт высоты iframe: верхний, боковые и нижний отступы живого примера
  теперь одинаковы;
- браузерная проверка контролирует ширину компонентов и выравнивание области превью.
- страница `Button` облегчена до одного интерактивного playground вместо десяти
  iframe и 147 одновременно отрисованных кнопок; полная матрица из 140
  комбинаций сохранена в machine-данных и проверках.
- над настройками `Button` добавлена компактная полка из шести M-разновидностей
  с ведущей иконкой, настоящим hover и быстрым выбором тона для playground.
- ведущая иконка Figma-вариантов `Button` приведена к SVG 24×24 с viewBox
  `0 0 24 24`; edge/gap зафиксированы как 8/4, 12/6 и 16/8 px для M/L/XL.
- ширина Button вынесена из вариантов в контекстные layout-правила для обычного
  контента, карточек курсов, мобильных форм и полноширинных действий секций.
- для `IconButton` добавлена компактная линейка `default / hover / focus / disabled / loading`
  по Courses Figma node `653:664`: корпус 36×36, SVG-иконки 24×24 и внешний focus-контур;
- `FilterChip · Basic` и исторический `Tab` объединены в семейство `FilterChip` без
  изменения id и адресов; для расширенного варианта зафиксированы имена
  `FilterChipMenu` и `FilterChipSwitch`;
- для `FilterChipMenu` и `FilterChipSwitch` показаны все состояния из Courses Figma,
  включая левую иконку, правый switch, loading и открытый dropdown;
- `SegmentedControl` и `ButtonGroup` объединены в семейство `Tabs` и получили
  контекстные имена `HeroTabs` и `PageTabs`; для обоих показаны полная группа и
  состояния default, hover, focus-visible, selected, disabled и loading.
- у группы `HeroTabs` добавлена единая полупрозрачная подложка с радиусом 12 px
  по Courses Figma node `4261:1716`; состояния сегментов накладываются поверх неё.
- у группы `PageTabs` добавлена единая подложка `#F1F1F1` с padding 4 px и
  радиусом 16 px по Courses Figma node `4813:288`.
- превью `SearchInput` исправлено: вместо тёмного фрагмента SSR-заглушки теперь
  показано настоящее production-поле с плейсхолдером, SVG-иконкой и focus-within;
  исходная заглушка без потерь остаётся в архиве v0.1.
- `Select`, `MultiSelect`, `SearchInput` и `TextInput` объединены общей Figma-анатомией:
  M 40 px и XL/SearchForm 56 px, текст 16/22, radius 12, gap 4, иконки 24×24;
- для семейства полей добавлена компактная матрица пустого/заполненного содержимого
  в состояниях default, hover, focus, disabled и error с настоящими hover/focus;
- добавлен новый `Textarea` по Courses Figma: высота 82 px, отступы 12×8 и та же
  матрица состояний; компонент отмечен как design-source-only.
- на страницах `Select` и `MultiSelect` показан открытый dropdown по Courses Figma:
  gap 4 px, панель 216 px, строки 40 px, прокрутка и настоящий hover строк.
- `Checkbox` и `Switch` сверены с Courses Figma и теперь показывают матрицу
  `inactive / hover / focus / disabled / loading` для off/on;
- добавлен Figma-only компонент `RadioButton` с той же полной матрицей состояний;
- для групп Checkbox и RadioButton зафиксированы интервалы: 16 px по вертикали,
  24 px по горизонтали и 8 px между контролом и подписью.
- у подписей `Checkbox`, `RadioButton` и `Switch` верхний внутренний отступ
  скорректирован с 2 px до 1 px.
- `SiteHeader` расширен до полного Figma-семейства из 21 device-комбинации:
  `ListingHeader`, `CoursesHeader`, `SimplePageHeader`, уровни Hero/Page и sticky;
- для SiteHeader зафиксирована компонентная шкала mobile ≤479, tablet 480–1023,
  desktop ≥1024, таблица применения и точные высоты; production-снимок сохранён.
