## Когда использовать

Ссылка — самый частый элемент продукта: **867 узлов `<a>`** на 10 из 10
снятых страниц. Отдельного «компонента ссылки» у продукта нет: есть правило
на теге и утилиты, которые накладывает место.

**Правило.** Используйте для перехода по адресу. В продукте 867 узлов на 10/10 страниц: подвал (230), `LinkGrid` (129), сквозные ссылки карточек (`CourseCard` 96, `PersonCard` 88), шапка (80).

## Когда не использовать

- Для действия без адреса — `Button`.
- Для выбора варианта — `FilterChip`.

## Как работает

`<a>`: внутренние адреса — 560, внешние — 305; в новой вкладке открываются 224 ссылки. Цвет и подчёркивание при наведении задаёт базовый слой (`a{color:var(--color-links-main)}`, `a:hover{text-decoration:underline}`); общего класса у ссылки нет — корень элементный.

## Управление клавиатурой

Корень — ссылка `<a href>`: фокус по Tab, переход — Enter. Кольцо `focus-visible:outline` стоит у 19 узлов из 867; у остальных своего кольца и сброса нет — работает фокус браузера. 224 из 867 открываются в новой вкладке (`target="_blank"`).

## Анимация

Классов перехода и анимации в разметке нет: наведение и другие состояния сменяются мгновенно.

## Почему корень элементный

Это единственная запись пакета с корнем вида `element:<тег>`, и основание
измерено, а не выбрано:

- узлов `<a>` — **867**, из них **без класса вовсе — 0**;
- классов, стоящих на **каждом** узле, — **0**;
- самый частый класс — `text-ui-black-850`, и он стоит на **42.9%** узлов.

То есть класса, который был бы у ссылки всегда, не существует. При этом
правило продукта у ссылки есть, и оно висит на теге — принято на R0-03,
лежит в `ui/foundations.css`:

```css
a{color:var(--color-links-main);text-decoration:none}
a:hover{text-decoration:underline}
```

Введённый корень `crs-link` пришлось бы наделить объявлениями, и они стали бы
**вторым носителем** тех же значений — ровно тем дефектом, ради которого в
пакете заведён гейт `tools/validate-showcase-claims.mjs`. Поэтому решением
владельца от 10 сентября 2026 в `conventions.cssRoot` заведена третья форма
корня, а `tools/validate-components.mjs` научен её проверять: тег обязан
стоять в позиции селектора в `ui/` и обязан встречаться в снятой разметке.

## Разметка

Правило продукта применяется к любому `<a>`, поэтому минимальная форма —
без единого класса:

```html
<a href="#doc-components">ссылка без единого класса</a>
```

Снятый узел для сравнения — ссылка-логотип из шапки:

```html
<a href="/courses" class="inline-flex items-center" title="Хабр Курсы" rel="nofollow"><img src="../ui/assets/images/logo.svg" alt="Хабр Курсы" width="97" height="32"></a>
```

## Внешний вид

Собственного вида у ссылки два свойства — цвет и подчёркивание, оба из правила
на теге. Всё остальное приносит место: размер текста, раскладка, обрезка,
поведение при наведении. Распределение классов по 867 узлам:

| класс | узлов | доля |
|---|---:|---:|
| `text-ui-black-850` | 372 | 42.9% |
| `absolute` | 230 | 26.5% |
| `bottom-0` | 230 | 26.5% |
| `left-0` | 230 | 26.5% |
| `right-0` | 230 | 26.5% |
| `top-0` | 230 | 26.5% |
| `text-small` | 226 | 26.1% |
| `hover:no-underline` | 183 | 21.1% |
| `py-0.5` | 160 | 18.5% |
| `hover:underline` | 160 | 18.5% |
| `phone:py-0` | 160 | 18.5% |
| `z-2` | 158 | 18.2% |

Четыре класса позиционирования (`absolute`, `inset`-пара и соседи) идут
вместе и на одной доле — это ссылка-оверлей, растянутая на карточку: она
делает кликабельной всю карточку, а не подпись в ней.

## Ограничения

- **Роли не разведены.** 867 узлов — это и ссылка в тексте, и пункт подвала,
  и оверлей поверх карточки, и элемент каталога. Одна запись описывает их все,
  потому что общего у них ровно одно — тег. Развести по контекстам — работа
  шага R3-03, и она требует разбора корпуса, а не переписи.
- **Проза выведена из переписи корпуса.** Правило применения, «Когда не использовать», «Как работает», клавиатура, анимация и адаптив написаны 11 сентября 2026 по переписи десяти снятых страниц (`.pipeline/R2-bulk/corpus-facts.json`, генератор `gen-prose.mjs`) и `notes` реестра. Разделов «Название и текст», «Валидация», «Слоты · Props» нет: подтвердить их в снятом продукте нечем.
