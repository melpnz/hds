# CatalogMenu

Адаптивное меню каталога Курсов. Макет принят владельцем как нормативный. Компонент пока не найден в production-разметке, поэтому служебный корень `crs-catalog-menu` нельзя считать публичным классом продукта.

## Структура

- Поиск показывается только на мобильном первом уровне.
- `ButtonGroup` переключает каталоги «Для взрослых» и «Для детей».
- На desktop и tablet первый уровень — вертикальный список направлений с иконками.
- Второй уровень разбит на смысловые группы с заголовками, ссылками и действием «Смотреть все».
- На mobile первый уровень заменяется плитками с изображениями; под основными направлениями находится группа «Может быть интересно».

## Адаптивность

| Ширина | Первый уровень | Второй уровень |
|---|---|---|
| `1024+` | список с иконками | сетка из трёх колонок групп |
| `744–1023` | список с иконками | одна колонка групп |
| `360–743` | три колонки плиток | открывается отдельным экраном |
| `320–359` | две колонки плиток | открывается отдельным экраном |

Desktop и tablet не заменяют иконки изображениями. Изображения используются только в мобильной плиточной системе.

## Составные части

- `.crs-catalog-menu` — контейнер панели.
- `.crs-catalog-menu__search` — мобильная строка поиска.
- `.crs-catalog-menu__list` и `.crs-catalog-menu__row` — первый уровень desktop/tablet.
- `.crs-catalog-menu__groups`, `.crs-catalog-menu__group` — структурный второй уровень.
- `.crs-catalog-menu__tiles`, `.crs-catalog-menu__tile` — мобильный первый уровень.
- `.crs-catalog-menu__suggestions` — мобильная группа дополнительных направлений.

Все размеры, цвета, типографика и радиусы берутся из токенов Courses. Иконки desktop/tablet лежат в `ui/assets/icons/catalog/`, мобильные изображения — в `ui/assets/images/catalog/`.

## Доступность

- Списки направлений размечаются через `nav` с явным `aria-label`.
- Текущий пункт первого уровня получает `aria-current="page"`.
- Декоративные иконки и изображения имеют пустой `alt`.
- Кнопка возврата имеет текстовую метку.
- Переключатель взрослого и детского каталога использует `aria-pressed`.

## Ограничения

- Макет фиксирует открытое состояние. Закрытое состояние принадлежит кнопке каталога в шапке и отдельно здесь не дублируется.
- В витрине переключатель показывает взрослое и детское содержимое, включая разные наборы иконок, мобильных изображений и групп второго уровня.
- Переход на второй уровень в mobile должен открывать отдельное состояние/экран; текущая витрина показывает только первый уровень.
