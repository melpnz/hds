### Подробнее по находке 1

`checkUnit` начинается с

```js
const RE_LOOKS_LIKE_MARKUP = /<\/?[a-z][\w-]*(?:\s[^<>]*)?>/i;
function checkUnit(unit) {
  if (RE_LOOKS_LIKE_MARKUP.test(unit.text)) return;
```

Единица — это абзац разметки, HTML-комментарий или комментарий CSS целиком.
Сущности в HTML декодируются **до** этой проверки (`decodeEntities`), поэтому
`&lt;span&gt;` в прозе тоже считается тегом.

Воспроизведение четвёртого проявления (проба `R1`): в тот же комментарий
`showcase/components.css:703–706` добавлена строка

```
Разметка лампочки: <li class="doc-bp__row"><span></span></li>.
```

Больше ничего не менялось. Результат:

```
Проверено 780 единиц текста витрины (1 html + 1 css) против разбора 17 файлов ui/.
Клауз с сущностями 175, из них о ui/ 9; числовых утверждений 25. Расхождений нет.
EXIT=0
```

Воспроизведение третьего (проба `R1`, вторая): в абзаце
`showcase/components.html:1374–1385` восстановлено «поднимает только два» и в то же
предложение добавлено `через <code>&lt;span&gt;</code>`. Находка `bp.prefixes.ui`

На текущем дереве фильтр гасит **12 единиц** (`review-1.markup-skip.log`), из них

Перепись это не показывает: с фильтром 176 клауз, без него 193, и разница

### Подробнее по находке 2

```js
const seg = tail.split(/,|\sи\sв\sтом\sчисле|\bв\s+том\s+числе\b/)[0];
```

Третья альтернатива мертва по той же причине, которую шапка гейта объявляет
исправленной: `\b` перед «в» требует ASCII-буквы слева, `\b` после «числе»
— ASCII-буквы справа. Работает только вторая альтернатива, и только при
союзе «и», и первая — по запятой.

```
проба R2:  «В ui/ не раскрывается ни одна утилита, кроме px-6 в том числе
            small-phone:text-center.»                        → EXIT=1, находки нет
контроль:  та же фраза с запятой перед «в том числе»          → claim-negative
```

Это ровно тот класс тихого пропуска, ради которого заведён шаг: утверждение
формы четвёртого проявления (отрицание существования о `ui/` с исключением)
проходит без единого слова в выводе. Замена на кириллически-безопасную границу
восстанавливает находку и оставляет регрессию 51/51 — то есть регрессия эту
форму не покрывает.
