# R6-02 · Витрина организаций `/education_centers` — отчёт сборки

11 сентября 2026. Статья — `pages/education-centers-listing.md`, живой
пример — `showcase/pages.html#p-education-centers-listing`.

## Что снято

С продакшена ничего нового. Опора — снимки инвентаризации
`evidence/source/production/pages/education-centers-listing/` (7 сентября) и
корпус CSS (8 сентября). Каркас — отрисовка `dom.html` (на 768, 375 и 320 —
`dom-<w>.html`) с CSS корпуса на 1440, 1024, 768, 375 и 320. Высота страницы
сошлась со скриншотами в пределах 0,7%, на 768 — точно.

## Порядок, по которому собрано

1. `.pipeline/pages/hydration-diff.mjs` — новый инструмент: ищет узлы,
   видимые в отрисовке без скрипта и нулевые в живом снимке `computed*.json`.
   Проверен на `/courses`: сам нашёл заглушку поиска, которую первая сборка
   нашла глазами. На витрине организаций на 1440 и 375 — 0 узлов.
2. Состав по областям — перепись селекторов по прямым детям основной
   колонки: `page-structure.mjs` здесь выбрал корень неверно (обёртку всей
   страницы), и блоки перечислены пробой по заданным контейнерам.
3. Настройки сборки — `pages-config.mjs`: 8 карточек школ из 20, три
   карусели заглушкой (баннеры, популярные курсы, журнал; у двух последних
   один селектор, заглушке добавлен индекс совпадения).
4. Шесть классов обёрток подняты из корпуса (ключ
   `page-education-centers-listing` в `extra-classes.json`).
5. Сверка `diff-page.mjs` — сначала одно расхождение (ниже), после правки
   слоя — 0 на пяти ширинах (586–591 узел).

## Что нашла сборка

1. **31 scoped-правило Vue поднималось в слой дословно и не срабатывало.**
   Три недостающих класса страницы — `bg-gradient-violet`, `-blue`, `-pink`
   (фон обложки-заглушки школы) — объявлены только правилами вида
   `.bg-gradient-violet[data-v-82d04e71]`. Съёмка срезает `data-v-*`, и такие
   правила не срабатывают ни на одном узле пакета. В `ui/utilities-components.css`
   их лежало 13: заглушка поиска в шапке, отступ поля ввода
   (`.wrapper--with-search input`), скрытие полос прокрутки у полосы рубрик и
   ряда чипов, сетка слота adfox, размер `h3` в `Prose`. Решение поднимать
   такие правила без атрибута было записано ещё для `swiper-button-shadow`
   (`ui/components/actions.css`), но `gen-utilities.mjs` его не выполнял.
   Теперь выполняет (`unscope`), и так же снимают область видимости с CSS
   корпуса обе сверки — `diff-page.mjs` и `hydration-diff.mjs`. На `/courses`
   заглушку поиска прячет правило слоя, и генератор её больше не удаляет.

   Снятие атрибута проверено на разметке пакета: правила вида
   `[data-v-…] .x` становятся общими, но `.style-ugc h3` в разметке нет ни
   разу, а `.wrapper input` стоит только на полях ввода.
2. **Межфайловый каскад.** У `h1` hero классы `m-0 mx-auto`; в корпусе
   `.mx-auto` идёт после `.m-0` и побеждает, а в пакете `.mx-auto` лежит в
   `ui/layout.css`, подключённом раньше `utilities-components.css` с `.m-0`, —
   заголовок прижимался к левому краю (сверка: margin 0 против 212 на 1440).
   Новый `.pipeline/pages/cascade-check.mjs` ищет такие пары по всей
   разметке витрины с учётом специфичности, `!important` и одинаковых
   значений — нашлась только эта. `.mx-auto` объявлен в
   `utilities-components.css` ещё раз, на своём месте из корпуса (ключ
   `cascade` в `extra-classes.json`).
