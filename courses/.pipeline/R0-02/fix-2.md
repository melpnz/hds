## 1 · major · граница 767/768, а не 744

Находка принята полностью. Подстановка была именно та, что назвал ревьюер:
за границу взята ближайшая снятая ширина.

**Проверено заново, тремя независимыми источниками.**

1. **CSS живой сборки.** Инлайновый `<style>` страницы `/courses` плюс
   11 внешних `.css` скачаны 8 сентября (корпус CSS 124 267 символов).
   `.phone\:flex-wrap{flex-wrap:wrap}` лежит внутри `@media (max-width:767px)` —
   это тот самый класс, который слой называл в том же предложении.

2. **Evidence пакета, уже принятый.**
   `evidence/source/production/media-queries-cold.json` — холодная загрузка
   `/courses` на 13 ширинах, среди них **767**:

   ```
   byWidth 744 → headerH 108 · footerH 476
   byWidth 767 → headerH 108 · footerH 476
   byWidth 768 → headerH  64 · footerH 256
   ```

   То есть факт лежал в пакете и до ревью — шаг его не прочитал.

3. **Свой замер на живом проде**, playwright + msedge, независимо
   от ревьюера:

   ```

   760 → --header-height 108px · <header> 108 · max767 true
   767 → --header-height 108px · <header> 108 · max767 true
   ```
