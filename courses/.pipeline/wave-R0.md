## Exit criteria R0 — сошлось дословно

Проверено приёмкой R0-06 целиком (полный разбор — `ROADMAP.md`, раздел
«Проверка exit criteria R0 приёмкой R0-06»):

1. `ui/courses.css` подключается одной строкой и отдаёт токены и шкалу — **сошлось**.

3. Валидатор запускается и проходит на пустом реестре — **сошлось**.
4. CSS витрины не пересекается с `ui/` ни одним селектором — **сошлось**

## Пригодность пакета — явно

Токены, типографика, шрифт, раскладка, утилиты, реестр компонентов
(55 записей, все измерены браузером) и каркас витрины — годны к использованию
и не потребуют пересборки при вёрстке компонентов.

**Пакетом как источником готовой разметки пользоваться нельзя.** В
`components/` — 0 спецификаций, все 55 записей `manifest.json` в статусе
`planned`. Волна R0 закрывает только инфраструктуру (токены, типографика,
сетка, реестр, каркас, витрина); ни один компонент ещё не свёрстан.

**Релиз пакета не предлагается.** Версионировать пока нечего показывать
пользователю пакета, кроме внутреннего каркаса — по таблице `VERSIONING.md`
статус `courses/` остаётся «релиз не объявлен» до появления хотя бы первых
принятых компонентов (R2).
