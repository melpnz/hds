# Замеры адаптивных страниц Хабр Курсов

Срез 1 октября 2026 года. Генерируется `tools/build-production-page-atlas.mjs` из гостевых captures. Это evidence, а не API UI Kit. Геометрия в CSS px; координаты относительно верхнего края документа после возврата наверх.

Контрольные ширины: 1440, 1024, 768, 744, 480, 393, 320. Отдельные граничные замеры: 767 и 1023 для шести представителей семейств.

Живые локальные эталоны: [атлас страниц](../../viewer/pages.html). Правила: [сборка страниц](../guide/production-pages.md).

## Решения владельца для новой сборки

- PersonHeader до768: вертикальная композиция без рамки и padding, фото100, имя30/34, gap20. От768 сохраняется горизонтальная карточка с рамкой и padding24. Публичный API не меняется. Доработка пока не опубликована.
- Рекламный Carousel variant=ad-slot: active568×232 по центру от768, соседние scale.87 и opacity.65, spaceBetween−26; mobile во всю колонку с aspect272/280 и spaceBetween0; loop с шагом1. AdSlot собирается из Carousel и AdCard. При одном баннере стрелки и пагинация не рендерятся. Доработка пока не опубликована.
- Обычные Carousel: loop=true, шаг1, gap12; CourseCard 4/3/1, ArticleCard и ReviewCard 3/2/1. Default loop=false сохраняет конечный режим. Если все карточки помещаются, блок стрелок не рендерится. Swiper внутри кита, живые карточки из slots. Рекламная геометрия описана отдельным решением banner-carousel. Доработка пока не опубликована.
- CardGrid: tabletColumns=2|3, default=2; columns=2|3|4, default=4; phone=1. Gap всегда 12 px, без prop для отступа. Старые вызовы сохраняют 4/2/1. Изменение пока не опубликовано.
- ReviewCard variant=wide: отзыв занимает всю ширину колонки, использует avatar48, рейтинг в колонке164 справа от768 и следующей строкой до768; текст не обрезается и fade не показывается.
- ReviewCard variant=full показывает весь текст без overlay-ссылки. От768 дата под звёздами, оба выровнены вправо; до768 звёзды и дата в одной строке слева, дата справа. Доработка принята 05.10.2026, не опубликована.
- ReviewCard принимает avatar, courseLogo, courseHref, advantages, disadvantages и comment. Compact остаётся default и сохраняет прежние text/href вызовы.
- PromoCard expired=true показывает метку «Завершено», приглушает логотип и содержимое, использует нейтральную плашку и рендерит настоящее disabled-действие без href.
- PromoCard: активные код и предложение открывают PromoCodeModal с условиями. Код копируется в модалке; внешний сайт открывается только отдельным действием. Открытие не раскрывает код внутри карточки и не открывает сайт автоматически. expired блокирует действие; open-code сохраняется. Кодовая кнопка с хвостом и отогнутым уголком — специальный вариант PromoCard, не Button.
- SiteHeader family=courses level=page принимает breadcrumbs и title, показывает левый h1 30/34 (phone 24/28) внутри синего фона и сохраняет production-позицию полосы фильтров на семи контрольных ширинах. Отдельный CategoryIntro не создаётся.
- SiteHeader принимает contributors{name,role,href,avatar}, verified, verifiedLabel, updatedAt и updatedDateTime. От1024 видны два участника и stack; 768–1023 — первый и stack; до768 — подпись «Авторы», stack и сокращённая мета. Отдельный ContributorsStrip не создаётся.
- Курсы школы собираются обычным CardGrid с tabletColumns=3 и gap12. Лимиты 8/6/4 задаёт страница, не компонент. Gap16 в measurements остаётся фактом о production, но новая kit-сборка использует утверждённые 12 px.
- PageHero и SearchForm собирают шапку через публичные slots. Единый градиент принадлежит внешней области, без повторного старта. Табам сохраняются отступы. Все dropdown получают options и выбранные значения; fixture-фильтры не являются backend.
- Форма промокодов школы имеет заполненные options и выбранную школу; на mobile открывается из сводки, после применения закрывается. Внешняя область шапки задаёт единый градиент.
- Белая панель без серого фона страницы; иллюстрация справа от768, mobile скрыта. У преимуществ экспертов иконки. Перед заголовком шагов40, до сетки24. PersonCard переносит имена внутри padding и принимает разные реальные логотипы и контакты.
- RatingTable: длинный текст увеличивает высоту с сохранением padding; все колонки доступны локальным скроллом на320. После последнего NumberedCourseItem нет линии; подборка рейтинга в каталоге содержит10 школ. SchoolCard: название максимум3 строки, кнопка внизу. Carousel: карточка заполняет слайд, стрелки центрируются без учёта пагинации. Подборки используют общий LinkGrid и соответствующие разделу данные.
- EntityHeader: логотип сверху без смещения при раскрытии. Desktop Подробнее в конце текста, Свернуть под ним; mobile обе ссылки под текстом. InfoTable gap16 по обеим осям и16 от заголовка.
- Хлебные крошки переносятся со стрелкой непосредственно после текста. По клику на stack и проверено открываются модалки; кнопки вертикально: Узнать больше про экспертов, затем Закрыть. У участников аватар48, описание чёрное с отступом от заголовка, роль серая под ФИО; в модалке проверки нет лишних отступов вокруг текста.
- Prose width=full. Разделы профиля по общему левому краю, gap40 перед экспертизой, квалификациями и историей; нет общего заголовка Опыт и образование. ProfileHistory: логотип48, gap12 до текста, название16/1.3 weight600 максимум2 строки, дата14/20 серая, внутренний gap4, gap24 между записями и от заголовка.
- Обратная ссылка: серый chevron, margin24 сверху и снизу, без дополнительного padding40 и gap48 перед отзывом. Рейтинг full: desktop справа, дата под звёздами; mobile слева, дата справа от звёзд.

## Границы измерений

- Гостевые заполненные страницы на 01.10.2026. Число карточек, цены, рейтинги, даты и реклама — данные, не правила геометрии.
- Production-reference — локализованный инертный снимок DOM/CSS, не компонентный frontend и не доказательство соответствия UI Kit.
- В reference отключены analytics, backend, отправка форм и переходы наружу; управление лентами — локальный адаптер для изучения геометрии, не production Swiper.
- Открытые фильтры, авторизация, ошибки и загрузка дополнительных данных не входят в этот срез.
- При расхождении со старым корпусом 08.09.2026 для этих 12 адресов приоритет имеют текущие измерения. Не распространять исключение одного семейства на все страницы.
- Автоматическая сборка через provider возможна только в пределах его публичного API. Неподдержанный вариант — запрос владельцу, а не CSS-переопределение внутри layer.
