# Иконография Courses

Активный implementation provider использует `UIcon` из Nuxt UI и коллекцию
Tabler. Передавайте имя иконки в формате `i-tabler-<name>`, например
`i-tabler-search`, `i-tabler-chevron-down` или `i-tabler-star-filled`.

Собственный `SpriteIcon` и старый `sprite.svg` не являются частью публичного API
кита. Старые материалы о спрайте сохранены только как историческое evidence.

Размер и цвет иконки задаёт родительский компонент через токены. Декоративная
иконка скрывается от accessibility tree; интерактивность всегда принадлежит
кнопке или ссылке вокруг неё, а не самой SVG.
