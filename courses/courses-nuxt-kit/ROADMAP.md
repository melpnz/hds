# Роадмап Courses UI

Актуализировано: 1 октября 2026 года. Текущая версия — **1.1.0**.

В активной очереди остаются только нерешённые задачи. Закрытые вопросы по
композиции, токенам, FilterChip со свитчем и восьми дефектам механики удалены;
история изменений находится в [changelog](layers/courses/CHANGELOG.md) и Git.

## Активная очередь

- Расширять visual regression на overlays, формы и составные карточки:
  сейчас эталоны покрывают шесть поверхностей на 320 / 480 / 768 / 1024 px.
- Автоматизировать публикацию release ZIP, SHA-256 и статического каталога
  из одного проверенного tag. Локальная сборка архива уже существует;
  публикация пока выполняется явно владельцем.

## Правила работы

- Не объединять компоненты только из-за внешнего сходства, если различаются
  семантика или ARIA-поведение.
- Использовать публичные варианты и параметры, а не переопределение внутренностей
  дочерних компонентов через селекторы по тегам и `:deep()`.
- Использовать семантические токены соответствующей категории.
- Проверять изменения на 320, 480, 768 и 1024 px и запускать применимые
  автоматические проверки; визуальные эталоны не обновлять автоматически.

## Известные границы

- Полный браузер иконок витрины требует локальный `/api/tabler-icons`;
  иконки компонентов входят в клиентский пакет и работают на статике.
- Динамические имена иконок приложение перечисляет в `icon.clientBundle.icons`.
- Спорные Figma-цвета требуют доказательной сверки по
  [roadmap гайда](../ROADMAP.md#точка-продолжения--следующая-сессия).
