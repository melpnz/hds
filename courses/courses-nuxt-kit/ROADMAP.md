# Роадмап Courses UI

Актуализировано: 1 октября 2026 года. Опубликованная версия — **1.2.0**.

Канонический UI Kit владельца — действующая библиотека; замена не планируется.
Решённые вопросы остаются в [changelog](layers/courses/CHANGELOG.md) и Git.

## Текущий результат

- Visual regression: 20 поверхностей/состояний на 320 / 480 / 768 / 1024 px.
  80 сценариев, по цветному и геометрическому эталону для каждого.
- Рабочая палитра определяется UI Kit; резервные CSS-переменные сохраняются
  для совместимости. Отчёт: `../machine/reports/provider-color-usage.json`.
- HeaderDropdown и расширение тестов входят в релиз 1.2.0.
- Пять пунктов сверки с Оплатой включены в 1.2.0: ручка SortSheet,
  цвета и доступное имя FilterChip, opt-in ширина OptionList и счётчик/события
  фильтров SiteHeader. Изменения описаны в changelog 1.2.0.
- Настроена подготовка черновика релиза на GitHub: проверки точной ревизии,
  ZIP слоя и каталога, SHA-256. Публикация вручную; инструкция —
  `../../tools/README-courses-release.md`.

## Отложено

- Сверка страниц с production/Figma — вернуться по решению владельца.


## Правила работы

Использовать публичные параметры компонентов и семантические токены;
не переопределять внутренности через селекторы тегов или :deep().
Проверять четыре контрольные ширины. Новые снимки просматривать до принятия;
старые эталоны не обновлять автоматически.

## Известные границы

Полный браузер иконок требует локальный /api/tabler-icons; иконки компонентов
работают на статике. Динамические имена приложение перечисляет в
icon.clientBundle.icons. Адрес Оплаты в HeaderDropdown — https://payment.habr.com.
