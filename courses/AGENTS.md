# Контракт для модели · Хабр Курсы v1.0

Размеры интерфейса берутся из `machine/dimension-tokens.json`, production-палитра — из `machine/tokens.json`, а нейтральные назначения активного provider — из `machine/semantic-tokens.json`; CSS-переменные подключаются через `ui/courses.css`. Масштабируемая база — `0.25rem` при эталонном root `16px`; границы и толщина focus ring остаются в `px`, line-height использует безразмерные токены. Новые размеры не записывай литералами. Остальные значения сверяй с `machine/reports/dimension-exceptions.md` и не округляй без дизайнерского решения.

Канон пакета — адресные файлы `machine/`; viewer лишь отображает их.

## Текущая реализация

Текущий implementation provider — `courses-nuxt-kit/`. В продуктовом проекте
его `layers/courses` копируется локально и считается vendored/read-only кодом:
не изменяй, не форматируй и не переименовывай файлы внутри layer. Разрешено
создавать любые application-компоненты, wrapper-компоненты и композиции страниц
вне layer, используя его публичные props и slots.

Если публичного API не хватает, опиши недостающую возможность и подготовь запрос
владельцу кита вместо локального форка. Изменять канонический
`courses/courses-nuxt-kit/` можно только в явно поставленной владельцем задаче по
поддержке самого кита. Первоначальная установка отсутствующего layer по
зафиксированным URL из `machine/consumer-workflow.json` разрешена и обязательна
для реализации в Nuxt. Не обращайся к GitHub только ради проверки наличия более
новой версии без прямой просьбы пользователя.

## Порядок чтения

1. `machine/index.json` — статус, границы, активный implementation provider и
   доступные проверки.
2. Для Nuxt открой `machine/consumer-workflow.json` и проверь локальный
   `layers/courses/courses-kit.manifest.json`. Если layer отсутствует — скачай
   указанные там release-архив и checksum, проверь SHA-256 и скопируй
   `layers/courses` целиком. Если GitHub недоступен, сообщи об этом; не
   воспроизводи компоненты кита вручную. Существующий layer без прямого решения
   пользователя не заменяй.
3. `machine/compatibility.json` — проверенная пара версии гайда и локального
   provider. Если версия локального manifest не перечислена как совместимая,
   не смешивай её с этим гайдом без отдельной сверки.
4. `machine/providers/courses-nuxt-kit.json` — компактное соответствие
   стабильного guide-id текущему export/source/preview. Для выбранного компонента
   открой только его `apiFile`: там находится сгенерированный публичный API
   (`props`, `slots`, `emits`, `models`). Если mapping прямой, используй компонент,
   а не перевёрстывай его по example или скриншоту. Владение полями описано в
   `machine/providers/README.md`.
5. Для нового продукта, страницы или общего визуального языка — `machine/style-profile.json`; для одного компонента этот шаг не нужен.
6. `machine/catalog.json` — найти нужную сущность по id, группе или tags.
7. Только `file` выбранной записи.
8. Затем только названные в записи `rules`, `implementation`, `examples` и
   evidence. Подробную прозу читать по `source.spec`.

Не загружать весь каталог, все SVG или evidence без необходимости. Записи со
scope `design-source-only` не являются фактом о production. Если разметка
равна `null`, соблюдать `missingReason` и `fallback`, а не достраивать DOM.

## Сборка интерфейса

- Для новой страницы сначала выбрать ближайший файл из `machine/patterns/`.
- Использовать порядок `sequence`, геометрию `frame` и связанные правила.
- Если локально доступен текущий implementation provider, использовать его
  публичный компонент. Изолированный example остаётся источником поведения и
  fallback-разметки, но не поводом повторно верстать уже существующий компонент.
- Для guide-only сущности без provider mapping разметку брать из изолированного
  example; классы являются контрактом с `ui/courses.css` и не переименовываются.
- Простые элементы используют intrinsic preview, модули и страницы — viewport
  320 / 480 / 768 / 1024 / Auto.
- Комментарии и допущения хранятся в `previewNotes`, а не внутри iframe.
- Тексты и числа сверять с `machine/content.json`.

## Границы

Пакет описывает гостевую публичную часть десяти снятых страниц. Не выдумывать
личный кабинет, тёмную тему, серверные ошибки, отсутствующие состояния или
раскладку Swiper. Все пробелы должны быть названы пользователю явно.

Версия v0.1 хранится в `archive/courses/v0.1` только для сверки и не является
обычной точкой входа.
