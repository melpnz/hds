# Инструменты пакета Courses

Пять скриптов. Запускаются из корня пакета (`courses/`), Node без сборки.

## Съёмка продакшена

```bash
node tools/capture.mjs --url https://career.habr.com/courses \
  --selector ".course-card" --out evidence/source/production/course-card
```

Снимает узел и кладёт в `--out`: `dom.html` (разметка с вычищенными
фреймворк-атрибутами), `computed.json` (computed styles по всему поддереву),
`tokens.json` (кастомные свойства `:root` и подключённые шрифты), `<width>.png`
на каждой ширине и `meta.json` с URL, селектором, состоянием и датой.

Ключи: `--widths`, `--state hover|focus-visible`, `--channel`, `--wait`,
`--shot-timeout`, `--full-page`.

**Ширины по умолчанию — `320,375,744,768,1024,1440`.** Это не произвольный
список: 320 / 744 / 1024 — канонические брейкпоинты пакета (схема Figma,
решение пользователя 2 в [`ROADMAP.md`](../ROADMAP.md)), 375 / 768 / 1440
показывают поведение реализации, построенной на 480 / 768 / 1024. Съёмка
только одной из двух схем оставляет responsive-раздел спецификации без
доказательства.

Набор всё ещё неполон: границу 480 ни одна из шести ширин не пересекает
вплотную, а именно в интервале 375–744 подменяется реализация фильтра
(ревью R0-00). Досъёмка на 479/480 — строка X-15 в роадмапе.

> **Расхождение со скиллом `guide-build`.** Его §2 предписывает шагам R2–R5
> запуск с `--widths 375,768,1024,1440` — набор, где из трёх канонических
> ширин Курсов есть только 1024. Следование скиллу дословно воспроизведёт
> дыру в evidence, ради закрытия которой заведён шаг R0-00. **На R2–R5
> запускайте `capture.mjs` без `--widths`.** Конфликт записан строкой X-04
> в [`ROADMAP.md`](../ROADMAP.md) и остаётся открытым, пока скилл не поправлен.

`dom.html`, `computed.json` и `tokens.json` снимаются на самой широкой из
запрошенных ширин — это записано в `meta.json` полем `computedAtWidth`. Для
мобильной разметки нужен отдельный запуск с `--widths 320`.

### Что инструмент сообщает о своей работе

`meta.json` перечисляет в поле `widths` только те ширины, для которых PNG
действительно оказался на диске. Запрошенный список лежит рядом
в `requestedWidths`, несостоявшиеся съёмки — в `failedWidths` с причиной.
Если снята не каждая ширина, скрипт печатает это в `stderr` и выходит
с кодом **1**.

Так было не всегда: до доработки R0-01 ошибка съёмки глушилась
`.catch(() => {})`, а в `meta.json` писался **запрошенный** список. Узел,
скрытый на мобильных, давал четыре PNG из шести, «Снято» на экране и код 0 —
evidence врало о своей полноте. Сверка `meta ↔ диск` по уже снятым файлам
(шаг R0-00) показала, что ложных записей в них нет: баг не успел сработать.

Прогресс печатается по каждой ширине. `--shot-timeout` (по умолчанию 10000 мс)
ограничивает ожидание узла: раньше скрытый узел давал 30 секунд тишины
на ширину.

## Локальный сервер

```bash
node tools/serve.mjs          # npm run serve
```

Отдаёт корень пакета на `http://127.0.0.1:4179` — витрина открывается по
`/showcase/components.html`. Нужен для проверки инварианта копируемости
(METHOD §6.1) и для Playwright: `playwright.config.mjs` поднимает его сам.

**Порт 4179, а не 4178.** На 4178 сидит сервер пакета `career/`. Общий порт
давал бы `EADDRINUSE` при `reuseExistingServer: false` и, хуже, один URL
витрины на два разных набора файлов — кто поднялся первым, тот и отдаёт,
молча. При старте сервер печатает корень, который отдаёт.

## Проверка реестра

```bash
node tools/validate-components.mjs            # errors
node tools/validate-components.mjs --strict   # errors + warnings, ненулевой код
```

Проверяет `components/manifest.json`: обязательные поля, kebab-case у `id`,
PascalCase у `canonicalName` и легаси-имён, уникальность имён и алиасов,
допустимые статусы, словарь состояний METHOD §5 (слова `active`, `focus`,
`select`, `inactive` запрещены), существование спецификации, CSS-корня в `ui/`
и якоря в витрине, а также что ни одна спецификация в папках категорий не
осталась вне манифеста.

Пока нет `components/manifest.json` (R0-05) и `showcase/components.html`
(R0-06), скрипт выходит с кодом 2 и говорит, какой шаг заводит недостающий
файл.

## Проверка классов разметки

```bash
node tools/validate-classes.mjs                   # витрины пакета
node tools/validate-classes.mjs путь/к/фиче.html  # своя разметка
```

Ищет классы, которые стоят в разметке, но не определены ни в одном CSS. Разметка
пакета — снимок продакшена на Tailwind, а `ui/` содержит только выписанные
руками правила: отсутствующая утилита не применяется молча, без ошибки
в консоли.

Своя разметка проверяется **только против `ui/`**. Если класс нашёлся лишь
в `showcase/*.css`, оболочка витрины протекла в компонент, и на пустой странице
с одним `ui/courses.css` он не сработает — это инварианты METHOD §6.1 и §6.2.

Чего скрипт **не** ловит: селектор витрины, случайно попавший в `ui/`. Это
обеспечивается префиксом `doc-` у классов витрины и проверяется на ревью.

Пока витрин нет (R0-06, R6), скрипт выходит с кодом 2 и называет шаг.

## Сверка заявленных чисел

```bash
node tools/validate-counts.mjs
```

Сверяет числа, записанные в прозе документации, с фактическим составом пакета:
шаги роадмапа, элементы и страницы реестра, категории `ui/components/`,
переменные `tokens.css`, записи манифеста. Счётчики правятся руками и
расходятся молча — документация продолжает утверждать старое число, и по нему
судят о покрытии. Ровно это уже случилось: роадмап заявлял 75 шагов при 76,
а README — «52 переменные, снятые с продакшена» при пустом `tokens.css`.

Правило проверки, которое перестало находить своё утверждение, — тоже ошибка:
скрипт говорит об этом отдельно, чтобы формулировку не потеряли вместе
с проверкой.

## Чего здесь нет

- `build-machine.mjs`, `validate-machine.mjs` — волна R8, вместе с машинным
  слоем.
- `validate-showcase-icons.mjs`, `sync-showcase-icons.mjs` — проверяют
  локальность иконок в витрине (METHOD §6.3). Витрины и спрайта пока нет;
  переносятся на R2-01 вместе со спрайтом. Строка X-06.
- `check-evidence-age.mjs` — обходит **плоские** `evidence/source/production/*.json`,
  а у Курсов снимки лежат в `pages/<id>/meta*.json`: нужен переписанный обход,
  а не копия. На снимках возрастом сутки порог 90 дней ничего не показывает.
  Строка X-05.
