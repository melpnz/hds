# Инструменты пакета Courses

Пять скриптов. Запускаются из корня пакета (`courses/`), Node без сборки.

## Съёмка продакшена

```bash
node tools/capture.mjs --url https://career.habr.com/courses \
  --selector ".course-card" --out evidence/source/production/course-card
```

Снимает узел и кладёт в `--out`: `dom.html` (разметка с вычищенными
фреймворк-атрибутами), `computed.json` (computed styles по всему поддереву),
`tokens.json` (кастомные свойства `:root` и подключённые шрифты), `<width>.png`
на каждой ширине и `meta.json` с URL, селектором, состоянием и датой.

Ключи: `--widths`, `--state hover|focus-visible`, `--channel`, `--wait`,
`--shot-timeout`, `--full-page`.

**Ширины по умолчанию — `320,375,479,480,744,768,1024,1440`.** Это не
произвольный список: 320 / 744 / 1024 — канонические брейкпоинты пакета
(схема Figma, решение пользователя 2 в [`ROADMAP.md`](../ROADMAP.md)),
375 / 768 / 1440 показывают поведение реализации, построенной
на 480 / 768 / 1024. Съёмка только одной из двух схем оставляет
responsive-раздел спецификации без доказательства.

Пара **479/480** добавлена 8 сентября 2026. R0-00 установил, что 480 —
несущая граница прода: на ней подменяется реализация выпадающего списка
фильтра (`base-modal` ниже, `v-popper--theme-dropdown` выше), а ниже 480
модалка становится нижним листом с хватом. Одиночная ширина показывает
результат, но не переключение, поэтому в дефолте стоят обе стороны границы.
Прежний набор из шести ширин её не пересекал — и без правки эта дыра
воспроизвелась бы на всех 55 элементах волн R2–R5. Разбор —
[`.pipeline/capture-log.md`](../.pipeline/capture-log.md), раздел «Главное:
ниже 1024 границ две — 480 и 768»; строка долга **X-37**
в [`ROADMAP.md`](../ROADMAP.md).

> **Расхождение со скиллом `guide-build`.** Его §2 предписывает шагам R2–R5
> запуск с `--widths 375,768,1024,1440` — набор, где из трёх канонических
> ширин Курсов есть только 1024. Следование скиллу дословно воспроизведёт
> дыру в evidence, ради закрытия которой заведён шаг R0-00. **На R2–R5
> запускайте `capture.mjs` без `--widths`.** Конфликт записан строкой X-04
> в [`ROADMAP.md`](../ROADMAP.md) и остаётся открытым, пока скилл не поправлен.

`dom.html`, `computed.json` и `tokens.json` снимаются на самой широкой из
запрошенных ширин — это записано в `meta.json` полем `computedAtWidth`. Для
мобильной разметки нужен отдельный запуск с `--widths 320`.

### Что инструмент сообщает о своей работе

`meta.json` перечисляет в поле `widths` только те ширины, для которых PNG
действительно оказался на диске. Запрошенный список лежит рядом
в `requestedWidths`, несостоявшиеся съёмки — в `failedWidths` с причиной.
Если снята не каждая ширина, скрипт печатает это в `stderr` и выходит
с кодом **1**.

Так было не всегда: до доработки R0-01 ошибка съёмки глушилась
`.catch(() => {})`, а в `meta.json` писался **запрошенный** список. Узел,
скрытый на мобильных, давал четыре PNG из шести, «Снято» на экране и код 0 —
evidence врало о своей полноте. Сверка `meta ↔ диск` по уже снятым файлам
(шаг R0-00) показала, что ложных записей в них нет: баг не успел сработать.

Прогресс печатается по каждой ширине. `--shot-timeout` (по умолчанию 10000 мс)
ограничивает ожидание узла: раньше скрытый узел давал 30 секунд тишины
на ширину.

## Локальный сервер

```bash
node tools/serve.mjs          # npm run serve
```

Отдаёт корень пакета на `http://127.0.0.1:4179` — витрина открывается по
`/showcase/components.html`. Нужен для проверки инварианта копируемости
(METHOD §6.1) и для Playwright: `playwright.config.mjs` поднимает его сам.

**Порт 4179, а не 4178.** На 4178 сидит сервер пакета `career/`. Общий порт
давал бы `EADDRINUSE` при `reuseExistingServer: false` и, хуже, один URL
витрины на два разных набора файлов — кто поднялся первым, тот и отдаёт,
молча. При старте сервер печатает корень, который отдаёт.

## Проверка реестра

```bash
node tools/validate-components.mjs            # errors
node tools/validate-components.mjs --strict   # errors + warnings, ненулевой код
```

Проверяет `components/manifest.json`: обязательные поля, kebab-case у `id`,
PascalCase у `canonicalName` и легаси-имён, связь между ними (`id` — kebab
от канонического имени), уникальность имён, алиасов, шагов роадмапа и селекторов,
существование спецификации, CSS-корня в `ui/` и якоря в витрине, соответствие
`status` своему определению в `statusDefinitions`, место записи в `ROADMAP.md`,
а также что ни одна спецификация в папках категорий не осталась вне манифеста.

Закрытые словари METHOD §5 — статусы, категории, виды, состояния и запрещённые
имена состояний — сверяются с METHOD **в обе стороны**: и «расширяет», и «не
содержит». Пакет их использует, но не переопределяет: иначе запрещённое слово
`active` вносится в разрешённые состояния правкой манифеста и проходит зелёным.

`productionEvidence` проверяется как утверждение об элементе, а не как заметка:
у записи `sourceScope: production` селектор обязан быть, быть разбираемым
и состоять из классов, которые действительно стоят в снятой разметке; у записи
не из продакшена его не должно быть вовсе. Числа `occurrences` и `seenOn`
сверяются с `components/selector-census.json` — см. следующий раздел.

Пока нет `components/manifest.json` (R0-05) и `showcase/components.html`
(R0-06), скрипт выходит с кодом 2 и говорит, какой шаг заводит недостающий
файл.

## Измерение селекторов

```bash
node tools/measure-selectors.mjs           # перемерить и переписать перепись
node tools/measure-selectors.mjs --check   # перемерить и ничего не писать
```

Прогоняет селекторы `productionEvidence` настоящим браузером (chromium, канал
msedge, JS выключен) по десяти `evidence/source/production/pages/*/dom.html`
и пишет измеренное в `components/selector-census.json` вместе с отпечатками
разметки, по которой оно снято.

Инструмент **только измеряет**: манифест он не трогает ни при каких флагах.
Числа реестра правит человек, руками, с записанной причиной.

Код возврата: 0 — измерено и сошлось с манифестом; 1 — измерено, но разошлось;
2 — измерять нечем (нет playwright) или не по чему (нет манифеста, нет снятых
страниц). Прежде расхождение печаталось, но кодом не отмечалось, и `--check`
не мог упасть ни при каком расхождении — как гейт приёмки он не существовал
(review-3, major 3).

Разделение существенное, и оно куплено дефектом: прежний инструмент
(`.pipeline/R0-05/check-selectors.mjs`) сверял `found` с `occurrences` и тем же
прогоном записывал `occurrences = found`. После прогона «сошлись 45 из 45» было
гарантировано конструкцией и не могло поймать неверный селектор — в том числе
тот, из-за которого `Breadcrumbs` числился снятым с продакшена. Запись
найденного и сверка с записанным не должны быть одной операцией.

Подпись прогона — `measuredBy`, `environment`, `measuredAt` — проверяется
`validate-components`: перепись обязана называть себя снятой этим инструментом
с `javaScriptEnabled: false` и датой не раньше самой ранней съёмки страниц.

Чего инструмент не даёт: перепись — файл в репозитории, и согласованная правка
**чисел** в манифесте и в переписи проходит зелёным. Настоящими числа делает
только прогон, поэтому на приёмке шага, трогавшего селекторы, `occurrences`
или `seenOn`, идёт пара команд — сначала перемер **без флага**, затем сверка:

```bash
node tools/measure-selectors.mjs
node tools/validate-components.mjs --strict
```

`--check` для этого не годится: он ничего не пишет, поэтому подделанная
перепись остаётся на месте и сходится сама с собой. Его место — быстрая
проверка «реестр против переписи» там, где перезаписывать перепись не нужно.

## Проверка классов разметки

```bash
node tools/validate-classes.mjs                   # витрины пакета
node tools/validate-classes.mjs путь/к/фиче.html  # своя разметка
```

Ищет классы, которые стоят в разметке, но не определены ни в одном CSS. Разметка
пакета — снимок продакшена на Tailwind, а `ui/` содержит только выписанные
руками правила: отсутствующая утилита не применяется молча, без ошибки
в консоли.

Своя разметка проверяется **только против `ui/`**. Если класс нашёлся лишь
в `showcase/*.css`, оболочка витрины протекла в компонент, и на пустой странице
с одним `ui/courses.css` он не сработает — это инварианты METHOD §6.1 и §6.2.

Чего скрипт **не** ловит: селектор витрины, случайно попавший в `ui/`. Это
обеспечивается префиксом `doc-` у классов витрины и проверяется на ревью.

Пока витрин нет (R0-06, R6), скрипт выходит с кодом 2 и называет шаг.

## Сверка заявленных чисел

```bash
node tools/validate-counts.mjs
```

Сверяет числа, записанные в прозе документации, с фактическим составом пакета:
шаги роадмапа, элементы и страницы реестра, категории `ui/components/`,
переменные `tokens.css`, записи манифеста. Счётчики правятся руками и
расходятся молча — документация продолжает утверждать старое число, и по нему
судят о покрытии. Ровно это уже случилось: роадмап заявлял 75 шагов при 76,
а README — «52 переменные, снятые с продакшена» при пустом `tokens.css`.

Правило проверки, которое перестало находить своё утверждение, — тоже ошибка:
скрипт говорит об этом отдельно, чтобы формулировку не потеряли вместе
с проверкой.
