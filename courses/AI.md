# Courses: короткий маршрут для ИИ

Гайд Courses v1.0 пригоден к использованию и продолжает развиваться. Текущая
реализация интерфейса — локально копируемый Nuxt layer `courses-nuxt-kit`; он
считается временным implementation provider до появления официальной библиотеки
frontend-команды.

## Если нужно собрать интерфейс

1. Открой `machine/index.json`, затем `machine/consumer-workflow.json`. Найди в
   проекте локальный `layers/courses/courses-kit.manifest.json`.
   Если Nuxt layer отсутствует, скачай `archiveUrl` и `checksumUrl` из workflow,
   проверь SHA-256 и скопируй архивный `layers/courses` в проект целиком. Если
   GitHub недоступен, сообщи об этом и не воспроизводи kit вручную.
2. Сверь его provider и версию с `machine/compatibility.json`. Без прямой просьбы
   пользователя не устанавливай обновление. Один раз в начале задачи выполни
   read-only проверку из `layers/courses/AGENTS.md`: новую версию только предложи,
   а изменённую локальную копию никогда не перезаписывай.
3. Открой компактный provider mapping и запись
   нужного компонента из её `apiFile`.
4. Используй готовый Vue-компонент из layer. Не перевёрстывай его по примеру или
   скриншоту и не меняй файлы внутри `layers/courses`.
5. Поведение, состояния, accessibility и композицию страницы возьми из одной
   выбранной записи `machine/catalog.json` и связанных с ней правил.
6. Собственные компоненты, wrappers и композиции создавай снаружи layer. Если
   публичного API недостаточно, зафиксируй пробел и подготовь запрос владельцу
   кита; не исправляй vendored-копию в продуктовом проекте.

Для подключения используй зависимости и `nuxtConfig` непосредственно из
`machine/consumer-workflow.json`. Не угадывай версии или структуру установки по
примеру. Проверку обновления запускай только по явной просьбе пользователя;
команда проверки не является командой обновления и не меняет файлы. Проверка
версии выполняется автоматически один раз за задачу; решение об обновлении
всегда остаётся за пользователем.

Для визуальной сверки локально запусти `npm run serve:integrated` из папки
`courses` и переключи источник превью на UI Kit. Статический HTML в viewer —
fallback и документация поведения, а не предпочтительная реализация Vue-
компонента.

## Кто за что отвечает

- kit: Vue-разметка, публичный API, текущие значения токенов, ассеты и визуал;
- machine-гайд: назначение, поведение, состояния, accessibility и page-patterns;
- provider mapping: соответствие стабильного guide-id конкретному компоненту и
  его API;
- `machine/compatibility.json`: проверенная пара версии гайда и provider;
- `machine/consumer-workflow.json`: скачивание, подключение, владение и
  безопасная проверка обновления;
- production и Figma: evidence для осознанного изменения, а не параллельная
  реализация внутри витрины.

Guide-only компонентов сейчас нет. Исторический `RubricationBar` свёрнут в
область `rubrication-navigation` pattern `courses-listing`: это нативный `nav`
с четырьмя `Link`, а не export Nuxt Kit. Полный контракт и границы находятся в
`AGENTS.md`, а правила provider — в `machine/providers/README.md`.
