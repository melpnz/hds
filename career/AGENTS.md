# Контракт Career machine-first

Это актуальный гайд Career v1.2. Начинай с
[`machine/index.json`](machine/index.json), затем следуй его `readOrder`.

## Как читать

1. Открой короткий `machine/catalog.json`.
2. Выбери один раздел и один адресный каталог из `file` или
   `groups[].file`.
3. Открой только `item.file` выбранной сущности.
4. `ruleFiles`, цветовые `groups`, examples и длинные guide sections
   загружай только по необходимости.
5. Не загружай все каталоги, компоненты, правила или assets для одной задачи.

## Как реализовывать

- Подключай `ui/career.css`.
- Если есть `markup.html`, используй его copy-safe разметку без
  переименования классов.
- `implementation.markup: null` означает, что DOM не снят: не сочиняй его.
- Разделяй `stateGroups.ui`, feature states и domain states.
- Учитывай `knowledge`, evidence, maturity и unknowns.
- Для непокрытого сценария используй ближайший паттерн и явно назови
  допущение. Не выдавай его за подтверждённое поведение Career.

Пакет покрывает опубликованный Career v1.2 в пределах гостевого публичного
среза. Авторизованные сценарии, живые ошибки форм и модальные потоки остаются
неподтверждёнными.
