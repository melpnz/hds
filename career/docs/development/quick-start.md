# Быстрый старт

Собрать экран Career с нуля. Пять шагов; после каждого можно открыть файл
в браузере и увидеть результат.

## 1. Подключить слой

```html
<link rel="stylesheet" href="career/ui/career.css">
```

Одна строка. Порядок слоёв, обёртка `.career-shell` и три добавленных правила —
[подключение](installation.md).

## 2. Выбрать семейство страницы

Career различает шесть продуктовых семейств, и от выбора зависит каркас:
LISTING · DETAIL · PROFILE · RATING · DASHBOARD · SERVICE. Разбор и признаки —
[компоненты, модули и семейства страниц](../guide/page-families.md).

Не подходит ни одно — значит задача в непокрытой зоне. Смотрите
[границы](../guide/coverage.md) прежде, чем достраивать.

## 3. Поставить каркас

Контейнер 1100 с полями `0 12px`, сетка `752 + 24 + 300`. Сайдбар фиксирован,
сжимается главная колонка.

```html
<div class="career-shell">
  <div class="page-width">
    <div class="page-layout">
      <main class="page-layout__main">…</main>
      <aside class="sidebar">…</aside>
    </div>
  </div>
</div>
```

Правила `SH-5`, `L-1`, `L-2` — [композиция](../guide/composition.md).
Обёртка `.career-shell` нужна потому, что `layout.css` написан на `@container`,
а не на `@media`.

## 4. Собрать содержимое из готовых компонентов

Найдите нужное в [реестре](../../components/INDEX.md), откройте спецификацию,
скопируйте блок «Разметка». Разметка любой спецификации работает на пустой
странице с одним `career.css` — вместе с иконками.

Живьём всё видно в [витрине](../../showcase/components.html); композиции
страниц с переключателями ширины — в [паттернах](../../showcase/pages.html).

Четыре правила, без которых экран не будет похож на Career:

- заголовок страницы лежит **внутри** первой карточки, вместе с поиском,
  сортировкой и счётчиком (`L-3`);
- шаг между карточками **12**, padding карточки **24**, радиус **24**,
  граница 1px — ни тени, ни подъёма при наведении (`L-4`, `C-1`);
- основное действие — **в шапке сущности**, а не в конце страницы (`D-4`);
- метаданные группируются микро-меткой 12/16 · 400 `gray-3` (`D-3`).

## 5. Проверить

Полный список — [чеклист готовности](checklist.md). Коротко:

- Четыре ширины: **375 · 768 · 1024 · 1440**. Оболочка перестраивается на
  **1023**, а не на 767 — медиазапрос сравнивается с шириной окна вместе
  с полосой прокрутки.
- Типографика **не** масштабируется: H1 остаётся 28/32 и на 375.
- Нет горизонтальной прокрутки документа.
- Состояния: default, hover, focus-visible, pressed, disabled — словарь
  и матрица обязательных в [`components/STATES.md`](../../components/STATES.md).
- Кольцо фокуса у полей показывается только при переходе Tab; за это отвечает
  необязательный `ui/focus-modality.js`.

## Чего делать не надо

Career узнаётся по пяти признакам, и нарушение любого ломает сходство сильнее,
чем неверный компонент: белый фон и границы вместо теней · холодная сине-серая
нейтральная шкала · фиолетовый только для действия, синий только для ссылки ·
микро-метка как способ группировки · высокая плотность. Разбор —
[дизайн-основа](../guide/design.md).

Если нужного паттерна в продукте нет — не достраивайте молча. Возьмите ближайший
подтверждённый как отправную точку и назовите допущение вслух: для этого есть
16 Decision Guides в [решениях](../guide/decisions.md), каждый с оценкой
уверенности и указанием, где заканчивается evidence.
