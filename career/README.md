# Career machine-first

Это актуальный гайд Career. Локальный снимок версии до миграции находится в
`../archive/career/v1/`; архив не публикуется и для использования гайда не нужен.

## Как читать ИИ

1. Открой `machine/index.json`.
2. Выбери раздел и открой только его `file` или один `groups[].file`.
3. Найди сущность в выбранном маленьком каталоге и открой только её `file`.
4. Для цветов открывай только нужную группу из `groups`.
5. Подтягивай `ruleFiles`, `implementation` и `examples` по необходимости.

## Что перенесено

- Все 95 опубликованных спецификаций компонентов и модулей: 72 индексированные сущности и 23 ранее не попадавших в машинный каталог документа.
- 57 правил композиции и 16 Decision Guides.
- 8 page-family паттернов и их responsive-контракты.
- Все 121 переменная, включая 113 цветовых токенов.
- Foundations: цвет, типографика, интервалы, радиусы, границы, тени, сетка и
  иконки.
- Product copy, component states, feature states и все 125 Markdown-документов старого пакета.
- Все 29 исходных JSON доступны отдельными адресными документами и загружаются только при раскрытии.
- Полный UI/assets: 265 изображений, включая 172 SVG; отдельно перенесены и показаны 97 evidence-скриншотов.
- Отдельные preview-файлы для каждой основы и page family. Монолитные showcase сохранены только в локальном архиве и не загружаются viewer.
- У preview два машинно-читаемых режима: `intrinsic` для основ и отдельных UI-элементов (без панели разрешений, высота по содержимому) и `viewport` для модулей и страниц (с проверкой адаптива).
- Навигация повторяет секции и категории `machine/catalog.json`; кнопки, формы, карточки, навигация и другие семейства не смешиваются в один плоский список.
- Все 72 привязки компонентов к 48 старым anchors разобраны без общих вкладок: 52 подтверждённых дубля сведены к каноническим примерам, 19 компонентов получили отдельный exact-DOM preview, а невизуальный `TransitionFade` явно отмечен без выдуманной разметки. Машинная карта решений: `machine/migration/component-examples.json`.
- 19 обзорных секций component showcase и 3 служебные секции page showcase оставлены только как архивные документы и больше не подключаются вкладками к компонентам.

Корневой каталог намеренно не содержит все 266 записей. Он направляет ИИ в
маленький каталог нужной области; полную карту загружает только viewer в
браузере.

Полный план сохранности: [`MIGRATION-CHECKLIST.md`](MIGRATION-CHECKLIST.md).

`npm run migrate` — локальная служебная команда: она требует архив
`../archive/career/v1/`. Обычное чтение, viewer и проверки опубликованного
пакета от архива не зависят.

## Посмотреть

```powershell
npm run validate
npm run validate:viewer
npm run serve
```

Viewer: `http://127.0.0.1:4174/viewer/`.

`iframe` в viewer изолирует CSS Career от оболочки документации. Внутри него открывается только выбранный specimen; общая витрина целиком не используется.
