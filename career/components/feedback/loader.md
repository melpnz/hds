## Нормативный контракт R2-E

Корневой класс — `base-loader`. SVG Loader скрывается от accessibility tree через `aria-hidden="true"`. Загружаемая кнопка, секция или список получает `aria-busy="true"`; при необходимости рядом остаётся визуально скрытый текст «Загрузка». Не назначайте каждому spinner `role="status"`: это создаёт повторяющиеся объявления.

При `prefers-reduced-motion: reduce` вращение замедляется, но индикатор не исчезает.
