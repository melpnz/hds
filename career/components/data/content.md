## Нормативный контракт R2-E

Content — style primitive (`editor__content`), а не stateful widget; собственных UI states нет. Внутренние ссылки, `details`, таблицы и media сохраняют нативную семантику и focus behavior.

- HTML до рендера санитизируется по allowlist; обработчики событий и опасные URL запрещены.
- Heading levels следуют структуре страницы, а не размеру шрифта.
- Таблицы получают caption или доступное имя; изображения — осмысленный `alt` либо пустой `alt` для декора.
- Для code/pre сохраняется горизонтальная прокрутка, для media — адаптивная ширина.
