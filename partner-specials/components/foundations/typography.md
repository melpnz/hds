## Когда использовать

Используйте семантические стили для заголовков, подписей и абзацев тематического партнёрского лендинга. Фиксированные f-стили подходят для текста, размер которого не должен переключаться между двумя наборами UI-kit. Сочетания задают промежуток между конкретными двумя текстами.

Выбирайте HTML-уровень заголовка по структуре документа. Имя визуального стиля h1 не требует тега h1: класс и атрибут можно назначить h2, если это заголовок раздела. Это новый HTML-контракт, а не извлечённый production API.

## Как работает

`.ps-type` задаёт кегль, межстрочный интервал и начертание. Атрибут `data-type` выбирает стиль, `data-weight="bold"` — полужирный фиксированный вариант. Родитель с `data-ps-type-mode="desktop"` или `mobile` явно выбирает набор; `auto` переключает его при ширине viewport 1024 px. По умолчанию действует desktop. Контейнер режима должен быть один: не вкладывайте контейнеры разных режимов друг в друга.

`.ps-type-pair` с `data-pair="h3-p1"` располагает два текста вертикально и сохраняет промежуток соответствующей пары. Допустимые 32 пары перечислены в таблице ниже; каждая имеет desktop и mobile. Пары с произвольными именами не получают промежуток автоматически.

## Внешний вид

Исходный текст — чёрный Inter. Клиентская тема переопределяет `--ps-type-font`, `--ps-type-color`, `--ps-type-heading-weight` и `--ps-type-body-weight`. Числовые токены кеглей, line-height и промежутков — геометрия UI-kit. При смене шрифта перепроверьте переносы; итоговая высота многострочного абзаца может измениться, хотя межстрочный интервал сохранён.

## Токены

Все 78 новых токенов перечислены с исходными значениями в таблице ниже и показаны с фактическими computed-значениями в [каталоге](../../showcase/typography.html#typography-tokens). Имена `--ps-type-*` — новая реализация, не production-переменные. Семейство шрифта использует локальные файлы уже принятого пилота. Переопределение темы ограничьте контейнером конкретного проекта.

## Responsive

Figma содержит desktop и tablet mobile без подтверждённого числового CSS-порога. `auto` использует media query `max-width: 1023px`; это явно выбранный новый контракт. Фиксированные стили не переключаются. Проверочные 320/768/1024/1400 — ширины проверки, не дополнительные брейкпоинты.

## Доступность

Текст сохраняет нативную семантику выбранного тега. Декоративные визуальные размеры не заменяют иерархию заголовков. Нет интерактивных состояний, анимации или дополнительных ARIA-атрибутов. Для клиентского цвета требуется читаемость на фактическом фоне проекта.

## Разметка

```html
<link rel="stylesheet" href="../../ui/partner-specials.css">
<section class="client-project" data-ps-type-mode="auto">
  <div class="ps-type-pair" data-pair="h3-p1">
    <h2 class="ps-type" data-type="h3">Вместе создаём полезные проекты</h2>
    <p class="ps-type" data-type="p1">Тематическая история и предложение партнёра.</p>
  </div>
  <p class="ps-type" data-type="f14" data-weight="bold">Фиксированная подпись</p>
</section>
```

Путь CSS в примере подходит для страницы в `.pipeline/typography/`; при переносе укажите путь к тому же единому CSS-входу. JS и стили витрины не требуются.

Тема поверх этого примера:

```css
.client-project {
  --ps-type-font: Georgia, serif;
  --ps-type-color: #362048;
}
```

## Ограничения

- Текстовый объём R1-01 включает семантические и фиксированные стили и 64 сочетания. List Vertical Item (`2081:766`) и Point (`2085:319`) ожидают оригинальный icon asset в R2-01. Полное семейство пока partial; размеры этих узлов сохранены, но их готовая разметка не заявлена.
- Точная версия Inter исходника неизвестна (P0-F01). Кегли и межстрочные интервалы воспроизведены, равенство ширины глифов с Figma не заявляется.
- Production runtime не снимался. HTML-API, сброс margin, перенос длинных слов и auto-порог — новая реализация по прямому заданию о Figma-геометрии и теме клиента.
- Общие правила всей типографики продакшена не выводились: указанные сочетания подтверждены конкретными компонентами Figma.
