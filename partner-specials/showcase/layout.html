Сетка спецпроекта

Поля, колонки и промежутки задают расположение элементов. Палитра клиента меняется отдельно. Пакет в разработке, без релиза.

По умолчанию используем числовые настройки сетки Figma. Нарисованный пример расходится с ними: поля 100 вместо 56 px на 1440/1920 и 36 вместо 40 px на 768. Ни один вариант не объявлен подтверждённым намерением автора.

Адаптация к текущему окну

Переключение на 768 / 1024 / 1280 / 1440 px — новая браузерная реализация. Это не снятые CSS-брейкпоинты.

Текущие токены

Значения читаются из CSS живого контейнера. Это геометрическая база, её не перекрашивают под клиента.

Семь размеров источника

Каждая полоса — реальная CSS-сетка выбранного профиля в указанной ширине, уменьшенная для сравнения. Цвет колонок — поясняющий слой витрины, не свойство Layout.

Перенести в проект

Подключите ui/partner-specials.css. Layout не добавляет цвет, минимальную высоту страницы или семантические роли.

<div class="ps-layout">
  <div class="ps-layout__grid">
    <div class="ps-layout__full">Содержимое секции</div>
  </div>
</div>
