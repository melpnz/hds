## Подтверждённые значения

`typography-details.json` содержит 28 вариантов семантической типографики с ID компонентов и текстов, размерами, font, weight, line-height, letter-spacing, textStyleId. Ниже размер/межстрочный интервал в px:

|---|---|---|
| h1 | 64/64 | 40/42 |
| h2 | 64/64 | 40/42 |
| h3 | 48/52 | 32/36 |
| h4 | 40/42 | 28/32 |
| h5 | 32/36 | 24/28 |
| h6 | 28/32 | 20/24 |
| t1 | 24/28 | 20/24 |
| t2 | 20/24 | 18/22 |
| t3 | 16/20 | 14/18 |
| PLead | 28/36 | 18/22 |
| p1 | 20/26 | 18/22 |
| p2 | 18/24 | 16/22 |
| p3 | 14/20 | 14/20 |
| p4 | 12/16 | 12/16 |

Все используют Inter: h/t — Bold 700, PLead/p — Regular 400. Letter-spacing и paragraph-spacing равны 0. h1 и h2 действительно совпадают по размеру и межстрочному интервалу; это подтверждено свойствами и обзором, исправлять предполагаемую ошибку дизайна нельзя. Ширина 400 — демонстрационный экземпляр элемента, не обязательная ширина любого текста на лендинге.

`typography-fixed-lists.json`: 10 фиксированных вариантов f12/f14/f16/f18/f20 × regular/bold: 12/16, 14/20, 16/20, 18/22, 20/28. Там же дерево List Vertical Item (`2081:766`, два варианта) и Point (`2085:319`, шесть вариантов).

`typography-groups.json`: геометрия 26 H+p, 24 H+t, 14 t+p сочетаний. Точные текстовые параметры вложенных элементов сохранены отдельно в `typography-pairs-2049-285.json`, `typography-pairs-2058-321.json`, `typography-pairs-2077-427.json`. Промежутки нужно брать из конкретного сочетания: например H1+p2 desktop 20, H2+p2 desktop 24; H1/H2/H3+p2 mobile 12, H4/H5/H6+p2 mobile 16. Их нельзя заменить одним универсальным gap.

List Vertical Item: ширина примера 568; строка 36, затем gap 16 и разделитель 1. Icon: контейнер точки 24×36, отступ до текста 12, левый отступ разделителя 36. Bullet: 6×36, отступ до текста 12, отступ разделителя 18. Текст PLead desktop 28/36. Point: icon big/medium/small 32×52 / 24×36 / 16×28; bullet 10×52 / 6×36 / 4×28. Вложенные иконки не экспортированы в этом проходе.

## Пробелы и границы

- Названия desktop и tablet mobile не устанавливают числовой CSS-брейкпоинт. Автопереключение будет новым контрактом с явным нормативом, либо размер задаётся потребителем.
- Полная версия Inter источника неизвестна; P0-F01 остаётся применимым. Числа font-size/line-height точны, ширина отрисованного браузером текста зависит от версии шрифта.
- Figma-обёртки служат организации коллекции: их ширины и размещение на canvas не становятся layout страницы.
- Иконка Point требует оригинального экспорта для реализации; геометрия дерева не разрешает перерисовывать glyph. Визуальный обзор фиксированных стилей, сочетаний и списков здесь не снимался, их структура и параметры прочитаны программно.
- Production runtime и состояние ссылок/интерактива не снимались. Данные относятся к исходному UI-kit, а HTML/CSS остаётся новой реализацией.

Все шесть JSON проверены парсингом. Первый запрос с привязками variables превысил лимит ответа; повреждённый результат не сохранялся. Полная таблица 28 вариантов повторно получена двумя ограниченными порциями без variable bindings; перед реализацией опираться на сохранённые числовые свойства и исходные textStyleId.
