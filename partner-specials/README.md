# Партнёрские спецпроекты

**Статус: в разработке, пилот текстовой кнопки. Релиз не объявлен.** Обновлено 8 сентября 2026 года.

Отдельный пакет для тематических коммерческих спецпроектов Хабра с клиентами. На странице присутствуют оба бренда; оформление обычно строится вокруг бренда клиента. Игры, тесты и другие интерактивы помогают удерживать внимание и связывают тему проекта с предложением партнёра.

Материалы ещё сырые: ИИ может ошибаться и додумывать отсутствующие детали. Доступны источники, реестр кандидатов и [пилот текстовой кнопки](PILOT.md). Пилот принят по [P0 в роадмапе](ROADMAP.md): проверены 30 вариантов на четырёх ширинах, смена темы, клавиатура, загрузка и копирование с одним CSS. [Приёмка](.pipeline/button/accept.md) сохраняет замечание о неизвестной версии Inter; весь UI-kit не объявлен готовой библиотекой.

## Посмотреть пилот

Откройте [витрину кнопок](showcase/components.html) через локальный сервер:

```powershell
cd partner-specials
npm install
npm start
```

Адрес и порт сервер выводит в терминал. Витрина показывает размеры и состояния, действие с загрузкой и переключение исходной/демонстрационной темы. Демонстрационная тема не является оформлением реального клиента. Для встраивания используйте [спецификацию Button](components/actions/button.md) и CSS-вход `ui/partner-specials.css`. Ограничения и статус проверки — в [роадмапе](ROADMAP.md).

## Как устроена будущая библиотека

| Слой | Что задаёт | Источник |
|---|---|---|
| Базовые элементы | Размеры, внутренние отступы, расположение частей, состав и адаптивные варианты | [UI-kit в Figma](https://www.figma.com/design/m2O8xRs2aEU8NfUpyNiAks/UI-kit?node-id=0-1) |
| Тема клиента | Цвета и состояния, семейства шрифтов, декоративная форма, изображения, фирменная графика | Материалы клиента; состав — [CLIENT-MATERIALS.md](CLIENT-MATERIALS.md) |
| Сценарий спецпроекта | Тема, порядок блоков, механика, контент, результат и переход к предложению клиента | Бриф конкретного проекта |

Это требование владельца пакета от 8 сентября 2026 года. Размеры из старых спецпроектов не заменяют базу Figma. Палитра демонстрационного UI-kit не становится обязательным стилем всех клиентов. Замена шрифта и декора требует проверки переносов, размеров и расположения элементов.

Figma фиксирует макет, но сама по себе не подтверждает браузерное поведение, семантику, переходы состояний и правила между показанными ширинами. Пробелы фиксируются отдельно. Игра не обязательна для каждого проекта; библиотека общих элементов не означает библиотеку готовых игровых движков.

## Покрытие

Сохранена структурная выгрузка 13 содержательных страниц Figma; Utilities содержит служебные аннотации и не входит в интерфейс спецпроекта. Для пилота дополнительно сохранены обзор, переменные и точная геометрия 30 текстовых вариантов Button. Остальной UI-kit требует поэлементной проверки. Иконковые кнопки, встроенные счётчики и дополнительные слоты не входят в пилот; всё семейство Button остаётся частичным.

Исследование содержит 18 примеров, включая встроенный в habr.com формат. Они перечислены как справочный корпус, а не как свежепроверенные шаблоны. Основной объём нового пакета — самостоятельные партнёрские лендинги; встроенный формат не переносится на них автоматически.

Пакет [landings/](../landings/README.md) сохраняет существующий путь и материалы брендовых/акционных лендингов. Здесь собирается отдельная база по направлению 08. Версия landings v0.1 не является версией partner-specials.
