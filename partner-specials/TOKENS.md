# Токены и кастомизация

Токен — CSS-переменная с понятной ролью. Компоненты читают её значение из темы: меняется переменная — меняется оформление внутри этого контейнера. [Единый редактор темы](showcase/theme.html) показывает Button, Typography и Layout вместе; готовый CSS можно перенести в проект.

Сейчас контракт покрывает принятую текстовую Button, текстовые стили Typography и сетку Layout. Это не полная выгрузка всего UI-kit. Имена `--ps-*` введены в новом пакете. Размеры и исходное оформление взяты из сохранённых Figma evidence; демонстрационная тема и браузерное поведение — новые решения. Пакет остаётся в разработке, без релиза.

| Основа | Значения и источник | Живой каталог |
|---|---|---|
| Button | [39 ролей](ui/tokens.css), [Figma](evidence/source/figma/button-details.json) | [Кнопки и токены](showcase/components.html#tokens) |
| Typography | [78 ролей](ui/typography-tokens.css), [спецификация и источники](components/foundations/typography.md) | [Типографика](showcase/typography.html#typography-tokens) |
| Layout | [11 базовых ролей](ui/layout-tokens.css), 3 вычисляемые роли контейнера, [спецификация и конфликт источника](components/foundations/layout.md) | [14 текущих значений](showcase/layout.html#layout-tokens) |

## Что меняется под клиента

| Слой | Параметры | Как использовать |
|---|---|---|
| База | Высоты, отступы, кегли, межстрочные интервалы, промежутки текстовых пар, размеры индикатора, поля и колонки сетки | Сохраняйте размеры UI-kit. Их изменение — отдельное отклонение проекта |
| Тема | Палитра, цвет текста, радиусы, семейство шрифта | Заполняйте по материалам клиента; проверяйте читаемость и переносы |
| Поведение | Длительность индикатора, внешний контур фокуса | Настраивайте отдельно с проверкой клавиатуры и уменьшения движения |

Семейство шрифта можно заменить; его метрики влияют на ширину кнопки. Геометрическая база не гарантирует одинаковую ширину текста во всех шрифтах. Сила внутренней обводки и прозрачность disabled взяты из источника: меняйте их осознанно, сохраняя различимость состояний.

## Подключить тему

Скопируйте `ui/` целиком и подключите свой CSS после основного файла. Применяйте атрибут к контейнеру: CSS-переменные наследуются его кнопками и текстом, сетка наследует геометрию библиотеки. Две темы могут находиться на одной странице. [client-theme.example.css](ui/client-theme.example.css) — готовый необязательный пример; основной CSS не подключает его автоматически.

```html
<link rel="stylesheet" href="./ui/partner-specials.css">
<link rel="stylesheet" href="./client-theme.css">

<section data-ps-theme="client">
  <div class="ps-layout" data-ps-type-mode="auto">
    <div class="ps-layout__grid">
      <div class="ps-layout__full">
        <div class="ps-type-pair" data-pair="h5-p1">
          <h2 class="ps-type" data-type="h5">Общая история</h2>
          <p class="ps-type" data-type="p1">Тематический проект клиента и Хабра.</p>
        </div>
      </div>
    </div>
  </div>
  <button type="button" class="ps-button ps-button--big">
    <span class="ps-button__label">Начать</span>
  </button>
</section>
```

Пример `client-theme.css` — демонстрационные значения, не брендбук клиента:

```css
[data-ps-theme='client'] {
  --ps-main: #7135b4;
  --ps-secondary: #964015;
  --ps-on-button: #ffffff;
  --ps-hover: #362048;
  --ps-hover-big: #362048;
  --ps-focus: #362048;
  --ps-disabled: #77717c;
  --ps-radius-big: 4px;
  --ps-radius-medium: 4px;
  --ps-radius-small: 4px;
  --ps-font: 'Partner Inter', Arial, sans-serif;
  --ps-type-font: var(--ps-font);
  --ps-type-color: #362048;
}
```

Все неуказанные значения наследуются из базы. У большой кнопки есть отдельный `--ps-hover-big`: изменение только `--ps-hover` не перекрасит её наведение. Внутренние `--ps-button-*` вычисляют выбранный размер и вид компонента; для клиентской темы используйте публичные роли ниже.

`--ps-type-font: var(--ps-font)` связывает текст с семейством кнопок в одном контейнере. Если брендбук предусматривает разные семейства, задайте `--ps-type-font` отдельно. Сначала подключите собственный web-шрифт через `@font-face`; экспорт редактора не загружает брендовые файлы. `--ps-type-color` задаёт обычный текст, `--ps-on-button` — подпись и индикатор кнопки. Контраст зависит от реального фона проекта.

В теме не переопределяются `--ps-layout-*`, кегли, line-height и gap текстовых пар. Смена семейства может изменить ширину кнопок, число строк и высоту абзацев. Сохранение геометрической базы означает постоянство её заданных параметров, а не одинаковые bounding boxes любого текста. Новые runtime-пороги Typography и Layout описаны отдельно в их спецификациях; тема их не меняет.

Исследование [08-partner-specials.md](../08-partner-specials.md), §2, §11, §19–20, помогает разделять техническую основу и оформление клиента. Его исторические rem-стратегия, переменные и брейкпоинты не переносятся в этот новый контракт: по текущему заданию размеры берутся из выбранного Figma UI-kit. Тема примера не является брендбуком какого-либо клиента.

## Палитра и форма

Здесь указана исходная тема Figma. В витрине значения обновляются при переключении темы.

| Токен | Исходное значение | Роль |
|---|---|---|
| `--ps-main` | `#2563eb` | Основное действие и цвет контура его фокуса |
| `--ps-secondary` | `#10b981` | Вторичное действие и его контур фокуса |
| `--ps-on-button` | `#fff` | Текст и индикатор загрузки на кнопке |
| `--ps-hover` | `#1f2937` | Наведение medium/small |
| `--ps-hover-big` | `#19212c` | Наведение big, составная заливка источника |
| `--ps-focus` | `#1f2937` | Фон при клавиатурном фокусе |
| `--ps-disabled` | `#9ca3af` | Фон недоступного действия |
| `--ps-disabled-label-opacity` | `.5` | Прозрачность подписи disabled, подтверждена [отдельной выпиской](evidence/source/figma/button-opacity.json) |
| `--ps-radius-big` / `--ps-radius-medium` / `--ps-radius-small` | `16px` / `12px` / `8px` | Форма углов по размерам |
| `--ps-stroke-big` / `--ps-stroke` | `4px` / `2px` | Внутренний контур фокуса big / остальных размеров; общий токен также используется внешним контуром |

Не выводите hover, focus и disabled автоматически из основного цвета: это отдельные состояния. Исходная зелёная secondary с белым текстом имеет ограничение контраста; палитра источника не считается утверждённой доступной темой клиента.

## Размеры базы

Во всех строках суффиксы идут в порядке `big` / `medium` / `small`.

| Семейство токенов | Значения | Назначение |
|---|---|---|
| `--ps-height-*` | `64px` / `48px` / `36px` | Высота кнопки |
| `--ps-py-*` | `18px` / `14px` / `8px` | Отступы сверху и снизу |
| `--ps-px-*` | `32px` / `20px` / `12px` | Отступы слева и справа |
| `--ps-font-*` | `20px` / `16px` / `14px` | Кегль |
| `--ps-line-*` | `28px` / `20px` / `20px` | Межстрочный интервал |
| `--ps-gap-*` | `12px` / `10px` / `10px` | Интервал частей; без дополнительных слотов текстовой кнопки не создаёт отдельный отступ |
| `--ps-spinner-*` | `24px` / `20px` / `20px` | Размер индикатора загрузки |

Высота secondary big loading в источнике — 60px. Пилот использует общий `--ps-height-big: 64px`, чтобы загрузка не сдвигала страницу. Это принятое проектное отклонение, а не новое измерение Figma.

## Шрифт и поведение

| Токен | Значение | Назначение |
|---|---|---|
| `--ps-font` | `'Partner Inter', Arial, sans-serif` | Семейство шрифта; собственный web-шрифт сначала подключите через `@font-face` |
| `--ps-weight` | `700` | Начертание; проверьте наличие нужного веса у клиента |
| `--ps-letter-spacing` | `0px` | Межбуквенный интервал базы |
| `--ps-focus-offset` | `3px` | Расстояние внешнего контура фокуса; новая реализация |
| `--ps-spinner-duration` | `900ms` | Период вращения; новая реализация, отключается при reduced motion |

## Проверка кастомизации

Проверьте обе кнопки во всех состояниях, включая большую при наведении и загрузке. Сверьте поля и колонки Layout, кегли и промежутки Typography до и после изменения темы. Высоты кнопок и их отступы сохраняются; смена шрифта требует отдельной проверки длинных русских подписей и переполнения. Сохраняйте видимый фокус и различимость недоступного действия. Полный комплект исходных материалов описан в [CLIENT-MATERIALS.md](CLIENT-MATERIALS.md).
