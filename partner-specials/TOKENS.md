# Токены и кастомизация

Токен — CSS-переменная с понятной ролью. Кнопка читает её значение из темы: меняется переменная — меняются все кнопки внутри этой темы. Пилот использует токены из [ui/tokens.css](ui/tokens.css); [живая витрина](showcase/components.html#tokens) показывает их фактические значения и пример настройки.

Сейчас это контракт текстовой Button, а не полная выгрузка переменных всего UI-kit. Имена `--ps-*` введены в новом пакете. Размеры и исходное оформление взяты из [Figma evidence](evidence/source/figma/button-details.json); демонстрационная тема и браузерное поведение — новые решения.

## Что меняется под клиента

| Слой | Параметры | Как использовать |
|---|---|---|
| База | Высоты, отступы, кегли, межстрочные интервалы, размеры индикатора | Сохраняйте размеры UI-kit. Их изменение — отдельное отклонение проекта |
| Тема | Палитра, цвет текста, радиусы, семейство шрифта | Заполняйте по материалам клиента; проверяйте читаемость и переносы |
| Поведение | Длительность индикатора, внешний контур фокуса | Настраивайте отдельно с проверкой клавиатуры и уменьшения движения |

Семейство шрифта можно заменить; его метрики влияют на ширину кнопки. Геометрическая база не гарантирует одинаковую ширину текста во всех шрифтах. Сила внутренней обводки и прозрачность disabled взяты из источника: меняйте их осознанно, сохраняя различимость состояний.

## Подключить тему

Скопируйте `ui/` целиком и подключите свой CSS после основного файла. Применяйте атрибут к контейнеру: CSS-переменные наследуются его кнопками. Две темы могут находиться на одной странице.

```html
<link rel="stylesheet" href="./ui/partner-specials.css">
<link rel="stylesheet" href="./client-theme.css">

<section data-ps-theme="client">
  <button type="button" class="ps-button ps-button--big">
    <span class="ps-button__label">Начать</span>
  </button>
</section>
```

Пример `client-theme.css` — демонстрационные значения, не брендбук клиента:

```css
[data-ps-theme='client'] {
  --ps-main: #7135b4;
  --ps-secondary: #964015;
  --ps-on-button: #ffffff;
  --ps-hover: #362048;
  --ps-hover-big: #362048;
  --ps-focus: #362048;
  --ps-disabled: #77717c;
  --ps-radius-big: 4px;
  --ps-radius-medium: 4px;
  --ps-radius-small: 4px;
}
```

Все неуказанные значения наследуются из базы. У большой кнопки есть отдельный `--ps-hover-big`: изменение только `--ps-hover` не перекрасит её наведение. Внутренние `--ps-button-*` вычисляют выбранный размер и вид компонента; для клиентской темы используйте публичные роли ниже.

## Палитра и форма

Здесь указана исходная тема Figma. В витрине значения обновляются при переключении темы.

| Токен | Исходное значение | Роль |
|---|---|---|
| `--ps-main` | `#2563eb` | Основное действие и цвет контура его фокуса |
| `--ps-secondary` | `#10b981` | Вторичное действие и его контур фокуса |
| `--ps-on-button` | `#fff` | Текст и индикатор загрузки на кнопке |
| `--ps-hover` | `#1f2937` | Наведение medium/small |
| `--ps-hover-big` | `#19212c` | Наведение big, составная заливка источника |
| `--ps-focus` | `#1f2937` | Фон при клавиатурном фокусе |
| `--ps-disabled` | `#9ca3af` | Фон недоступного действия |
| `--ps-disabled-label-opacity` | `.5` | Прозрачность подписи disabled, подтверждена [отдельной выпиской](evidence/source/figma/button-opacity.json) |
| `--ps-radius-big` / `--ps-radius-medium` / `--ps-radius-small` | `16px` / `12px` / `8px` | Форма углов по размерам |
| `--ps-stroke-big` / `--ps-stroke` | `4px` / `2px` | Внутренний контур фокуса big / остальных размеров; общий токен также используется внешним контуром |

Не выводите hover, focus и disabled автоматически из основного цвета: это отдельные состояния. Исходная зелёная secondary с белым текстом имеет ограничение контраста; палитра источника не считается утверждённой доступной темой клиента.

## Размеры базы

Во всех строках суффиксы идут в порядке `big` / `medium` / `small`.

| Семейство токенов | Значения | Назначение |
|---|---|---|
| `--ps-height-*` | `64px` / `48px` / `36px` | Высота кнопки |
| `--ps-py-*` | `18px` / `14px` / `8px` | Отступы сверху и снизу |
| `--ps-px-*` | `32px` / `20px` / `12px` | Отступы слева и справа |
| `--ps-font-*` | `20px` / `16px` / `14px` | Кегль |
| `--ps-line-*` | `28px` / `20px` / `20px` | Межстрочный интервал |
| `--ps-gap-*` | `12px` / `10px` / `10px` | Интервал частей; без дополнительных слотов текстовой кнопки не создаёт отдельный отступ |
| `--ps-spinner-*` | `24px` / `20px` / `20px` | Размер индикатора загрузки |

Высота secondary big loading в источнике — 60px. Пилот использует общий `--ps-height-big: 64px`, чтобы загрузка не сдвигала страницу. Это принятое проектное отклонение, а не новое измерение Figma.

## Шрифт и поведение

| Токен | Значение | Назначение |
|---|---|---|
| `--ps-font` | `'Partner Inter', Arial, sans-serif` | Семейство шрифта; собственный web-шрифт сначала подключите через `@font-face` |
| `--ps-weight` | `700` | Начертание; проверьте наличие нужного веса у клиента |
| `--ps-letter-spacing` | `0px` | Межбуквенный интервал базы |
| `--ps-focus-offset` | `3px` | Расстояние внешнего контура фокуса; новая реализация |
| `--ps-spinner-duration` | `900ms` | Период вращения; новая реализация, отключается при reduced motion |

## Проверка кастомизации

Проверьте обе кнопки во всех состояниях, включая большую при наведении и загрузке. Высоты и отступы сохраняются; смена шрифта требует отдельной проверки длинных русских подписей и переполнения. Сохраняйте видимый фокус и различимость недоступного действия. Полный комплект исходных материалов описан в [CLIENT-MATERIALS.md](CLIENT-MATERIALS.md).
