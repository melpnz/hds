# Аудит дополнения токенов

8 сентября 2026 года. Объект — принятый P0 и его текущий CSS-контракт, а не новый срез production или всего Figma UI-kit. Источники пилота сохранены в той же сессии; повторная съёмка не нужна для отображения уже реализованных переменных.

Пробел: пользователь видит две темы, но не видит роли токенов и их значения. В ui/tokens.css есть публичные роли, а спецификация объясняет их только группами. Значения темы уже меняют реальный CSS кнопки; каталог следует читать из computed styles, чтобы не создавать второй ручной источник значений.

План P0-T01: каталог, объяснение базы/темы/поведения, изолированное редактирование темы, копируемый CSS и проверка изменения значений без сдвига геометрии. Имена --ps-* остаются новыми именами пакета, не production-переменными. Дополнение не объявляет готовность всего UI-kit.
