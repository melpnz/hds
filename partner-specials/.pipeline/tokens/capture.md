# P0-T01 — токены пилота

Объём: показать существующие публичные роли Button и способ клиентской кастомизации. Числа берутся из текущего ui/tokens.css; Figma/production повторно не снимались. Токены --ps-* остаются новым контрактом пилота, не полным экспортом UI-kit.

Каталог содержит 39 публичных ролей: оформление12, база25, поведение2. Значения читаются через getComputedStyle контейнера основной матрицы при смене темы. Назначения и группы описаны отдельно, без дублирования значений в JS. Редактор изолирован от матрицы и экспортирует scoped CSS для data-ps-theme=client. Размеры базы не редактируются; смена семейства шрифта может изменить ширину подписи.

Исходный SVG spinner не изменён. CSS mask использует его контуры, а currentColor связывает цвет с --ps-on-button. Это расширение нового runtime-контракта.

Проверки: npm run test:tokens и npm test -- --no-screenshots — PASS. Проверено совпадение всех публичных имён с CSS, чтение значений двух тем, изоляция редактора, сохранение геометрии при смене цвета/радиуса, перенос экспортированного CSS на отдельную страницу, смена шрифта, reset и spinner color. Снимки раздела на320/1400 — evidence/verification/tokens, report.json рядом. Общее поведение Button проверено30вариантов×4ширины.

Первый прогон ожидал видимость строки внутри закрытого details и завершился timeout; проверка инвентаря заменена на наличие DOM, группа оформления по умолчанию раскрыта. Это не изменение API кнопки. Последующие проверки прошли. Временные изображения самопроверки удалены, канонические сохранены в evidence/verification/tokens.
