Общий набор для новых фичей, лендингов и макетов. **Если нужен логотип сервиса, бери SVG отсюда.** Не набирай название обычным шрифтом, не перерисовывай знак и не генерируй его как картинку. Для новых работ этот набор имеет приоритет над историческими логотипами в evidence и примерах пакетов. Существующие витрины не переписаны.

## Четыре варианта

- `wordmark-ru.svg` — русскоязычное текстовое название в кривых.
- `wordmark-en.svg` — англоязычное текстовое название в кривых.
- `icon-detailed.svg` — детализированный белый «катышек» на круглом фоне цвета сервиса; исходный viewBox 60 × 60.
- `icon-pixel.svg` — пиксельный знак для небольших размеров на скруглённом квадрате; исходный viewBox 16 × 16.

Язык выбирай по языку интерфейса или запросу. Для небольших иконок используй пиксельную версию, для крупного самостоятельного знака — детальную. Практический ориентир: пиксельная версия на 16–32 CSS px, детальная — около 60 px и крупнее; это рекомендация выбора, не официальный норматив минимальных размеров. Пиксельный вариант лучше выглядит в целочисленном масштабе 16/32 px. Не пытайся получить его уменьшением детального знака.

Сохраняй пропорции viewBox, цвета и геометрию. Не перекрашивай фон знака под акцент страницы: в файле уже задан цвет сервиса. Текстовые версии чёрные; отдельной светлой версии в этой поставке нет. Они не используют currentColor, поэтому CSS color не перекрасит их автоматически. Не выдавай самостоятельно изменённый вариант за исходный.

## Подключение

Скопируй нужные SVG в ресурсы проекта и подключай локально. Не используй адрес GitHub blob как src изображения. Например, для русского логотипа Карьеры:

```html
<img src="/assets/logos/career/wordmark-ru.svg"
     width="135" height="20" alt="Хабр Карьера">
```

Путь адаптируй к проекту. Width/height можно менять с сохранением соотношения сторон. Для декоративного логотипа рядом с тем же текстом используй пустой alt; у ссылки только с логотипом должно быть доступное имя.

SVG самостоятельные: без шрифтов, скриптов, внешних ресурсов и встроенных растров. ViewBox сохранён, фиксированные width/height из экспорта удалены — размер задаётся при подключении. Для экономии контекста прочитай эту таблицу или manifest.json и загружай только выбранный SVG, а не содержимое всех 28 файлов. Для обычного подключения через img читать данные path не требуется.

## Происхождение и оптимизация

Набор предоставлен владельцем репозитория в семи цветовых вариантах и четырёх форматах. Оптимизирован SVGO 4.1.0: компактная запись путей и цветов, удаление избыточных атрибутов, округление координат до трёх десятичных знаков, форматирование с отступами. Без перерисовки или упрощения деталей знака. Оригиналы сохранены локально в temp и не публикуются.

Общий размер SVG уменьшен с 335 395 до 166 255 байт (на 50,4%). Все 28 файлов сравнены с оригиналами рендером в Chrome при четырёхкратном размере; максимальная средняя ошибка цветового канала — 0,033 из 255. Побайтового или абсолютного пиксельного совпадения после округления не предполагается; визуальный каталог проверен.
