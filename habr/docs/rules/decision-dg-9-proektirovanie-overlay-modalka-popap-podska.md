### DG-9 · Проектирование overlay (модалка/попап/подсказка)

**OBSERVED.** Popover без варианта не содержит своего оформления (OV-2).
Dialog не просто уменьшается на мобильном, а меняет форму на bottom-drawer
(OV-1). Три вида Hint решают разные задачи, не один параметризуемый (OV-4).

**Context/When.** Нужен новый всплывающий элемент.

**Prefer.** Определить сначала **вид**, не оформление: контекстная
подсказка у элемента (Hint), содержательная панель (Popover + variant),
блокирующее модальное окно (Dialog). Для Dialog сразу проектировать два
состояния — окно и шторку, не только десктопное.

**Avoid.** Проектировать Dialog как просто «уменьшенное окно» на мобильном
— единственное подтверждённое поведение overlay при сжатии экрана в этом
своде — это смена формы, не пропорциональное уменьшение.

**Evidence.** OV-1, OV-2, OV-4. **Confidence: MEDIUM-HIGH** для факта
смены формы, **GAP** для конкретного брейкпоинта переключения.
