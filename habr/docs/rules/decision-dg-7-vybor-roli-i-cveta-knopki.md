### DG-7 · Выбор роли и цвета кнопки

**OBSERVED.** Роль (Primary/Success/Danger/Minor) и форма (fill/line/text)
— независимые измерения (AC-1). Success работает как рабочая primary-CTA
в разных контекстах, не только «подтверждение успеха» (AC-2).

**Context/When.** Выбираешь кнопку для нового действия.

**Prefer.** Сначала форма (насколько действие акцентно: fill > line > text),
затем роль (Primary — нейтральное продолжение, Success — рекомендуемое
действие/подтверждение, Danger — необратимое/деструктивное, Minor —
второстепенное). Success можно рассматривать как primary CTA не только
в буквальном смысле «успех» — подтверждено в трёх независимых контекстах.

**Avoid.** Выбирать цвет кнопки по названию из CSS (`christi`,
`fuzzy-wuzzy-brown`) вместо роли — эти имена не несут семантики для
дизайн-решения, только для поиска класса.

**Evidence.** AC-1, AC-2. **Confidence: HIGH**

**GAP.** Danger/Minor в форме fill не подтверждены — если нужен акцентный
деструктивный CTA, готового класса нет (AC-3).
