### 9.2 · Admin form / wizard (entity creation)

| | |
|---|---|
| **Наблюдений** | 1 полный экран (шаг «Реквизиты» мастера заявки на блог) |
| **Confidence** | MEDIUM |
| **Статус** | **CONFIRMED** (Figma) |

**Layout regions.** Шапка Habr → заголовок задачи («Заявка на
корпоративный блог») как отдельная карточка → главная колонка: карточка
формы (заголовок раздела «Реквизиты компании» → radio-группа с обязательной
пометкой `*` → текстовые поля, одно — со счётчиком символов, одно —
с иконкой поиска внутри → подсказывающий текст под полем → футер формы:
«Вернуться» (ghost) + «Далее» (primary, зелёный)) → правый сайдбар:
**степпер прогресса** (5 шагов: Правила/Контакты/Тариф/Профиль/Реквизиты,
завершённые — зелёная галочка, текущий — синий номер).

**Reusable modules.** `Button` (ghost + success), `Checkbox`/`RadioButton`
(Figma-подтверждён, radio не заведён отдельно от checkbox — **GAP**, нужен
отдельный `RadioButton`), text input (не специфицирован — тот же
`tm-input-text-decorated`, что найден в production поиска).

**Primary actions.** «Далее» — зелёный, справа от «Вернуться» — вторичное
действие слева, первичное справа, стандартный порядок.

**Responsive / States.** Не подтверждено — Figma не давала альтернативных
состояний этого экрана.
