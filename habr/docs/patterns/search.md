Shell + форма `.search` + Tabs для типов «Публикации / Хабы / Компании /
Пользователи / Комментарии» + сортировка + результаты. Переданный URL
server-side отдаёт информационное состояние «нажмите на иконку поиска»;
результаты загружаются клиентом. Поэтому пример фиксирует именно это
информационное состояние и не подставляет фиктивный `ArticleCard`.
На мобильном поле и tabs сохраняют структуру и сжимаются с контейнером.
