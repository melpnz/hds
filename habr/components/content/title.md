## Назначение

Заголовок-обёртка + заголовок-ссылка на статью. Единственный компонент
выборки, где подтверждено переключение шрифта: обёртка `.tm-title` набрана
системным стеком (наследует от `body`), а `.tm-title__link` — **явно
задаёт `font-family: Fira Sans`**. Подтверждено дважды: перечнем CSS и
прямым `getComputedStyle` на живой `habr.com/ru/feed/` (h2-обёртка → системный
стек, `a.tm-title__link` внутри неё → Fira Sans). См.
`evidence/runtime-contract.md`, раздел «Шрифты».

## Анатомия

```html
<h2 class="tm-title tm-title_h2">
  <a class="tm-title__link" href="/articles/…">Заголовок статьи</a>
</h2>
```

## Варианты

| Класс | Кегль |
|---|---|
| `.tm-title_h1` | 24px/1.3, Fira Sans, основной цвет — **базовое** значение |
| `.tm-title_h2` | наследует кегль, `line-height:1` |
| `.tm-title__link` | 20px/1.3, Fira Sans, `:hover`/`:visited` → акцентный цвет — **тоже базовое, реально варьируется**, см. GAP |

**GAP исправлен после Visual Foundations pass.** Базовые 24px `.tm-title_h1`
— НЕ то, что видит пользователь на реальной странице статьи: заголовок
детальной страницы — **32px/40px**, через модификатор
`.article-snippet.full-article .tm-title_h1` (см.
`components/content/article-card.md`). Подтверждено дважды: CSS-правилом
и `getComputedStyle` на живом `habr.com/ru/articles/…`. Базовые 24px
`.tm-title_h1` без модификатора, судя по всему, применяются там, где H1
не является заголовком полноразмерной статьи — GAP, конкретное место
использования не установлено.

Аналогично `.tm-title__link` (карточка в ленте) на практике показывает
**диапазон 14–20px** в зависимости от типа карточки/размещения (замерено
на реальном фиде: 20, 18, 17, 16, 14px для разных модулей) — не один
плоский размер. Заголовок конкретно `ArticleCard` использует именно 20px
(см. спецификацию), но соседние модули (промо-блок, дайджест) явно задают
свои собственные меньшие размеры. Не считать 20px универсальным
"card title" — это title конкретно `ArticleCard`.

## Поведение

`word-break: break-word` + `overflow-x: auto` на обёртке — длинные слова
без пробелов (ссылки, идентификаторы) переносятся, а не вылезают за
контейнер и не обрезаются.

## Ограничения

Соответствие `_h1`/`_h2` реальным тегам `<h1>`/`<h2>` не проверено на
100% случаев — в снятой разметке `.tm-title_h2` стоит на `<h2>`, но CSS
не требует совпадения класса и тега.
