## Назначение

Список наград профиля — пилюли с иконкой, каждая со своей подсказкой
(`cursor: help`, заголовок через `title`/tooltip на самом элементе,
не через компонент Hint).

## Анатомия

```html
<div class="badges">
  <ul class="list">
    <!-- обычная награда: div, только текст -->
    <li class="item">
      <div class="badge" title="Описание награды"><span>Название награды</span></div>
    </li>
    <!-- награда-ссылка: a + иконка перехода -->
    <li class="item">
      <a class="badge" href="/ru/specials/…" title="Описание награды">
        <span>Название награды</span>
        <svg class="tm-svg-img badge-icon" width="11" height="11">
          <use xlink:href="#arrow-link-small"></use></svg>
      </a>
    </li>
  </ul>
</div>
```

## Устройство

Пилюля 32px высотой, `border-radius: 18px` (полное скругление по высоте),
поля `0 16px`, текст 12/16 w400, рамка и текст акцентного цвета
(`--accent-primary`), фона нет.

## Иконки у награды нет

Замер профиля с 14 наградами: иконка есть **ровно у одной** — той, что
ведёт на страницу акции. Она размечена `<a class="badge" href>`, а не
`<div class="badge">`, и получает `arrow-link-small` **11×11** после
текста с отступом `margin-left: 6px`. Остальные 13 — просто текст в
`<span>`.

То есть иконка обозначает **не награду, а возможность перехода**, и
берётся всегда одна и та же — стрелка ссылки. Не ставить её у обычных
наград и не подбирать иконку по смыслу награды.

## Ограничения

Состояние disabled/получено-не-получено не подтверждено — **GAP**: на
доступных страницах показаны только полученные. Содержимое tooltip
(`title`) — только нативный браузерный тултип, не компонент `Hint`.
