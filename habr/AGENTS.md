# Контракт Habr machine-first

Это гайд Habr v1.0 с частичным production-покрытием. Начинайте с
`machine/index.json`; для страницы или общего визуального языка затем читайте
`machine/style-profile.json`, для одного компонента этот шаг не нужен.

## Порядок чтения

1. `machine/index.json` — версия, границы и порядок чтения.
2. `machine/catalog.json` — найдите одну сущность по id/kind/tags.
3. Откройте только поле `file` выбранной записи.
4. Подключайте указанные implementation, rules, example и evidence адресно.
5. `machine/provenance` и архив нужны только для аудита, не для реализации.

## Реализация

- Подключайте `ui/habr.css`; тему задают `ui/themes/light-v2.css` или `dark.css`.
- Используйте готовую разметку компонента и его CSS-корень. Не копируйте
  повторяющиеся элементы в страницы вручную.
- Для новой страницы применяйте общие header, footer, shell, surface и grid.
- Проверяйте light и dark; цветовой литерал допустим только как зафиксированное исключение.
- Источник внешнего вида: production гостя → Storybook → Figma → явно
  обозначенное допущение. Company admin и авторизованные сценарии не считайте
  production-подтверждёнными без нового evidence.
- Размеры — из `machine/dimension-tokens.json`; line-height безразмерный,
  границы/focus ring остаются в px согласно политике пакета.

## Перед завершением

Запустите `npm run validate` и для визуальных изменений
`npm run validate:viewer -- http://127.0.0.1:4173`. Непокрытые места вынесите
в `unknowns` или `ROADMAP.md`, не заполняйте их стилем другого продукта.
