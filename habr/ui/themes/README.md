# Themes — палитра и назначения

Источники:

* **CSS** — `light-v2.css` / `dark-v2.css` в этой папке. Сверены с
  production (`assets.habr.com`) **токен в токен: 43 из 43 совпадают в
  обеих темах**, лишних и недостающих нет.
* **Назначения** — Figma `habr-lib`, страница палитры
  (node `3766-12196`), 42 свотча в 9 группах. Снято через
  `get_design_context` (текст), не с картинки.

## Формат значений: hsl, не hex

Продакшен объявляет все токены в **`hsl()`**, hex в файлах нет вообще.
В таблицах ниже hex приводится только как справочная величина из Figma —
**канон для кода — hsl**.

**Альфы в продакшене нет ни одной**: ни `hsla()`, ни `rgba()`, ни
`hsl(... / %)` — 43 токена, все непрозрачные. Прозрачность там, где она
нужна, считается на месте через relative color syntax, например
`hsl(from var(--icon-primary) h s l / 40%)` в `ui/components/tabs.css`.

## `--icon-primary-40` — есть в Figma, нет в CSS

Единственное расхождение по составу палитры:

| | |
|---|---|
| **Figma** | `--icon-primary-40` = `hsla(208,10,61,0.40)` |
| **Production CSS** | такого токена **нет** — вместо него значение инлайнится через `hsl(from … / 40%)` |
| **Значение** | одинаковое в light и dark (единственный такой токен вместе с `--header-text`) |
| **Назначение** | разделительные линии (календарь, табы, модальные окна), разметка графика «Просмотры», обводка кнопок-иконок / белого информера / цифр прогресса, фон иконки применённой функции в редакторе |

Мы **не добавляем** его в `light-v2.css`/`dark-v2.css` — это сломало бы
байтовое совпадение с production. Зафиксирован здесь как Figma-only.

## Что светлая/тёмная тема делают в общем случае

Почти для всех токенов Figma повторяет одну и ту же формулу: в светлой
теме оттенок светлее/насыщеннее, в тёмной — темнее/приглушённее, чтобы
сохранить контраст. Здесь это не дублируется в каждой строке — значения
обеих тем уже приведены в таблицах.

**Исключения — токены, которые НЕ меняются между темами:**
`--header-text` (всегда белый) и `--icon-primary-40` (всегда одна и та
же полупрозрачность). `--other-overlay-shadows` — наоборот,
единственный, который полностью инвертируется (чёрный ⇄ белый).
