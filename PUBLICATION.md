## Отправляем: вспомогательный слой

Эти материалы доступны по ссылкам, но не входят в обязательное чтение перед разработкой фичи.

| Файлы / папки | Решение | Причина |
|---|---|---|
| `*/evidence/**` | Отправляем, включая отобранные PNG | Подтверждения правил и визуальные примеры |
| `*/research/**` | Отправляем | История исследований и решений |
| `*/.pipeline/inventory.json` | Отправляем | Реестры используются проверками пакетов; не удалять вместе с журналами сборки |

Не исключаем все картинки, JSON и скрытые папки: среди них есть нужные ресурсы, реестры и доказательства правил. Журналы отдельных шагов сборки исключены адресно; опубликованные инструменты проверки и их зависимости сохраняются.

Наличие файла на GitHub само по себе не расходует контекст ИИ: объём чтения задаёт маршрут из README. Исключение evidence ради экономии токенов не требуется.

## Перед отправкой

1. Проверить `git status --short`: коммитить только выбранные изменения. Пока другой агент работает над `landings/`, не включать его рабочие правки массовым `git add .`.
2. Проверить `git ls-files -ci --exclude-standard`: команда показывает уже отслеживаемые файлы, которые теперь попадают под исключения. Сам .gitignore не убирает их из индекса.
3. Если такой файл есть, отдельно решить его снятие с отслеживания с сохранением локальной копии. Это не выполняется автоматически при разметке публикации.
4. Проверить список и содержимое подготовленного коммита: `git diff --cached --stat` и `git diff --cached`. Для отдельного нового файла причину исключения показывает `git check-ignore -v <путь>`.
5. Отправлять выбранный коммит, а не незакоммиченные файлы. Push отправляет также необходимую историю коммитов: исключение из текущего дерева не удаляет файл из старой истории.

Авторские папки `.audits/`, `.claude/` и `_sources/` сняты с отслеживания с сохранением локальных файлов. Исторические ссылки на них внутри пакетов обозначены в корневом README как внутренние источники; структура активно разрабатываемых пакетов сохранена. Это исключение из текущей версии, а не удаление из прошлых коммитов. История не переписывается.
