# blocks — статьи о блоках и реестр

Пусто. Заводит **R0-05**: `INDEX.md`, `manifest.json` и шаблон статьи.
`PATTERNS.md` с тремя рецептами страниц — **R4-01**.

Единица этого пакета — блок, а не компонент: продукт признан лендингом
(METHOD §1, BRIEF §1). Цепочка — примитив → блок → рецепт страницы.

Что здесь окажется:

```
INDEX.md        реестр для человека: что есть, где лежит, как читать статью
manifest.json   машиночитаемый реестр — предмет проверки validate-blocks
PATTERNS.md     три рецепта: франшиза, карьерное событие,
                корпоративная конференция (R4-01)
<id>.md         статья о блоке
```

Ожидаемый размер реестра — **24 записи**: 19 типов блоков и 5 примитивов
(`.pipeline/inventory.json`, `registryTotals`). Примитивы живут
в `components/`, их заводит R0-08 и волна R1; запись в реестре при этом
одна на элемент, где бы ни лежала статья.

Проверка сходимости — `node tools/validate-blocks.mjs --strict`: у каждой
записи обязаны существовать статья, CSS root в `ui/` и якорь в витрине
(METHOD §6.5). Пока файла `manifest.json` нет, проверка выходит с кодом 2
«проверять нечего», а не с зелёным нулём.
