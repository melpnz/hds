## Когда использовать

Всегда. Hero — единственный блок пакета с полным покрытием: он есть
у всех восемнадцати макетов, включая `1284:3362`, где нет шапки.

## Цвет заголовка

**Граница применения цвета:** `#5DF20D` снят на доске `5149:6443`
концепции «Неоновый БУМ» как неоновый декоративный акцент. Это не
постоянный цвет заголовков Хабра и не правило для всех его лендингов.
Покрытие 23/23 описывает исследованный набор баннеров, а не доказывает
универсальность палитры. Без явно выбранной концепции заголовок использует
`--core-text-primary`; зелёный декор включается только сочетанием
`data-product="habr" data-concept="neon-boom"` на корневом элементе.
Такое ограничение применения — норматив; сам оттенок снят из источника.
Цвет конкретного заголовка можно переопределить по его макету, но не выводить
его автоматически из наличия кислотного акцента.

## Размер и расположение

Hero — самая высокая секция страницы, и при этом **поле у него меньше
ритмического**. У `18085:3890` контентные секции идут по `padding-top: 156`,
а hero — по 32.

| Узел | Высота hero | Поле | Ширина артборда |

| `9519:2096` | **920** | не снято | 1600 |
| `12395:11001` | **764** | не снято | 1600 |

hero и тем, что под ним, не ставится ничего: следующая секция несёт своё поле
сама (правило К-1, 83 стыка из 85).

## Название и текст

Дисплейный заголовок hero имеет право быть **леттерингом в векторе, а не
набором** — правило Т-5, покрытие 7/18. Там, где он вектор, гарнитуры у него
нет вовсе: узлы отдаются SVG-ассетом.

| Узел | Как сделан дисплей |
|---|---|
| `10943:2349`, `10943:2387` | леттеринг в векторе |
| `9519:2174`, `9519:2205` | `boolean-operation`, растеризованный SVG |
| `12742:42` | 21 отдельная буква-`vector` |
| `1357:8543` | леттеринг в векторе |
| `6509:20481` | **наполовину шрифт**: Neue Machina 172 объединена с вектором булевой операцией |

Заголовок набирается прописными: uppercase стоит на дисплее `7882:20906`,
`14871:2798`, `6509:20482`, `1302:12203`.

### Фон hero

Единственный снятый по CSS фон hero — градиент:

```
linear-gradient(180deg,
  rgb(229,84,0) 0%, rgb(249,128,6) 21%,
  rgb(224,195,253) 65.975%, rgb(250,249,246) 100%)   /* 10943:2225 */
```

Подсветка фона hero пятью размытыми овалами измерена у `20216:120` —
узлы `20256:3561`, `:3562`, `:3564`, `:3565`, `:3566`. Снята **геометрия**:
`inset 0 0 57.7px 43px` и `inset 0 0 100.7px 52px`. Оранжевые `#d04509`
и `#a05024` того же узла — цвет проекта «Санаторий маркетолога»
(Хабр × eLama), покрытие 1 узел из 18, и в ядре они красили hero всех трёх
продуктов сразу. Поэтому роль лежит в `--product-glow-hero`: геометрия
снятая, тона берутся из семейства продукта и следуют теме. Снятый оранжевый
остался модификатором проекта `.hero-glow-sanatorium`.

### Стеклянная карточка в hero

`18085:3948` `hero-form-card` — рецепт снят целиком:

| Свойство | Значение |
|---|---|
| `background` | `rgba(255,255,255,0.1)` |
| `backdrop-filter` | `blur(30px)` |
| `border-radius` | `20` |
| `padding` | `40` |
| `box-shadow` | `inset 0 0 4px 0 rgba(255,255,255,0.3)` |

Тот же рецепт стоит на «стеклянном чипе» бренд-участка — стекло подтверждено
двумя независимыми источниками, а не одним.

## Ограничения

- **CSS hero снят у пяти узлов из восемнадцати** — `10943:2225`, `9519` (дата
  в hero), `7882:20901`, `6509:20475`, `18085:3930`, `1302:12200`. Про
  остальные тринадцать сказать нечего: у семи из девяти доснятых узлов
  `get_design_context` на весь артборд вырождается в метаданные.
- **Собственная заливка hero не снята у `9519:2096`**: поддерево слишком велико
  для одного вызова, меньшего узла с этой заливкой нет. Соседние секции дают
  `#eef1f0`, рендер аудита давал `#EFEFEF` — расхождение не разрешено.
- **Кегль 122.4 в дисплейном ряду встречается без node id.** В таблицу выше
  он не внесён: значение без адреса источником не является. Чтобы его
  подтвердить, нужен узел, на котором он измерен.
- **Внутреннее поле hero снято у одного узла** — 32 у `18085:3930`.
  У остальных семнадцати измерена только высота секции.
- **Расстояние от дисплея до кнопки не снято ни разу**; 32 px в CSS —
  норматив с маркером.
- **Двухколоночная раскладка `.hero-split` опирается на один узел** —
  `18085:3942` `hero_container`. Ширина правой колонки 420 px спроектирована.
- Мобильной раскладки hero нет: мобильных артбордов у 18 узлов пакета
  не установлено.
