# HDS Landings

Версия гайда: **v0.2, в разработке**. Материалы очень сырые. Для 11 русских Webflow-лендингов собраны отдельные source-driven черновики по фактической последовательности и типам блоков. Они ещё не прошли полную визуальную сверку, местами используют сокращённый контент и неполный набор исходных иллюстраций. Не выдавайте их за проверенное соответствие исходнику или продакшену.

Это статический UI kit для лендингов с собственным HDS reset, семантическими токенами, компонентами, блоками и темами. В активной версии не используется CSS-фреймворк. Inter загружается из Google Fonts; без интернета используется системный fallback. Для просмотра, сборки страницы и передачи разработчикам Node.js, localhost и сборщик не нужны.

## Быстрый старт

1. Скачайте или клонируйте репозиторий.
2. Дважды щёлкните `landings/viewer/index.html` — каталог и примеры работают напрямую через `file://`.
3. Для просмотра текущего черновика откройте `examples/pages/company/index.html`; остальные незавершённые страницы находятся рядом в `examples/pages/`.
4. Подключайте `ui/hds.css` и `ui/hds.js`: скрипт различает клавиатурный и pointer-фокус, а также обслуживает демонстрационную форму и мобильное меню.
5. Передавайте разработчикам всю папку `landings/`: пути внутри относительные, достаточно распаковать её в репозиторий.

Минимальное подключение:

```html
<html lang="ru" data-theme="company">
  <head><link rel="stylesheet" href="path/to/landings/ui/hds.css"></head>
  <body>…</body>
</html>
```

## Маршрут чтения

- Человеку: [витрина](viewer/index.html) → пример → [правила](docs/rules.md).
- Каталог разделён на атомы → элементы → организмы → блоки → страницы. У каждого организма и блока собственная HTML-страница и прямая ссылка; у элементов есть интерактивный стенд и явная матрица состояний для ревью.
- Основы: отдельные страницы [типографики](examples/typography/index.html), [цветов](examples/colors/index.html), [отступов](examples/spacing/index.html), [скруглений](examples/radii/index.html) и [брейкпоинтов](examples/breakpoints/index.html).
- ИИ: [machine/index.json](machine/index.json) → [machine/catalog.json](machine/catalog.json) → одна нужная спецификация из `machine/specs/`.
- Для новой темы: [theming.md](docs/theming.md).
- Происхождение решений и ограничения выборки: [source-audit.md](docs/source-audit.md).
- Следующие шаги: [ROADMAP.md](ROADMAP.md).

Текущая версия до перехода на собственный reset сохранена локально в `archive/landings/v0.2`; это архив для восстановления, а не источник актуальных правил.
