# HDS — конструктор лендингов

Основная витрина лендингов: элементы и типографика, 16 семейств, 34 варианта. **Статус: в разработке.** Перенос правил из прежних материалов ещё не завершён; демонстрационные решения не означают утверждённый норматив.

Запуск из корня репозитория: `node landings/tools/serve.mjs`.

Открыть: http://127.0.0.1:4180/showcase/index.html (HTML на GitHub отображается как код).

Для сравнения сохранены [прежние примитивы](primitives.html), [блоки](blocks.html) и [ядро](core.html).

## Управление

- Продукт: Хабр, Карьера, Курсы.
- Светлая и тёмная темы.
- Четыре уровня характера: Inter и Unbounded.
- Варианты внутри каждого семейства.

## Файлы и оформление

В шапке и подвале используем только текстовый SVG-логотип. Не объединяем текстовый знак с иконкой сервиса в один логотип.

index.html — оболочка, lab.js — компоненты и поведение, lab.css — базовая раскладка, hds.css — оформление лендингов.

Токены и шрифты подключены из landings/ui; SVG — из assets/logos. Восемь текстовых ролей, согласованные радиусы и цвета продуктов. Поля используют актуальную границу core-border-field.

Работают FAQ, выбор тарифа, вкладки и локальная проверка форм. Тексты, имена, отзывы и цены демонстрационные. Данные никуда не отправляются.

Исходный эксперимент в папке design остаётся локальным. Эта копия публикуется вместе с пакетом landings. До использования предупреди пользователя, что материалы сырые и результат требует внимательной проверки.
