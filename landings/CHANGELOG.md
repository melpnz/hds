# Changelog

## Unreleased

- Пакет переведён на собственный HDS reset без Pico CSS; базовые HTML-элементы и компоненты больше не получают неявные framework-стили.
- Снимок версии до перехода сохранён в `archive/landings/v0.2`.

- Полностью пересобран пакет на Pico CSS 2.1.1 и собственном семантическом слое HDS.
- Добавлена первая тема `company` по русскому Webflow-экспорту.
- Каталог разделён на атомы, элементы, организмы, блоки и страницы; для элементов добавлены интерактивные стенды и матрицы состояний.
- Организмы и блоки разнесены по самостоятельным HTML-страницам без якорной адресации общих галерей.
- Добавлены 11 схематичных архитектурных прототипов русских Webflow-лендингов, машинный инвентарь источников и автономная file-витрина. Прототипы не считаются визуально близкими реконструкциями до постраничной пересборки по источнику.
- Единый пятисекционный шаблон страниц удалён; вместо него добавлены 11 отдельных source-driven схем с исходным порядком и характерными группами блоков. Статус страниц остаётся `draft` до полной визуальной сверки.
- Восстановлены исходные медиа и состав сложных секций агентской программы, рассылки, корпоративных блогов, рекламы, Карьеры, стартапов и страницы компании; добавлены универсальные мозаики, блок «кейс + показатели» и расширенные формы.
- У карточек с медиа изображение вынесено до внешних краёв без внутреннего отступа; текстовая часть сохраняет системные поля на широких и мобильных экранах.
- Inter подключён через Google Fonts; локальные файлы шрифта удалены из пакета.
- Прежнее содержимое сохранено локально в `archive/landings/v0.1`.
