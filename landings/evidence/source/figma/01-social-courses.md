## Как читать этот файл

Это **третий** кандидат на продуктовую палитру Курсов, независимый от двух,
уже описанных в `5164-8025.md` и `5164-8169.md` (оба — доска «Собираем
обучение», файл `04_Brand`). `01_Social` — рекламные соцсети/баннеры,
отдельный файл Figma, названный владельцем именно как дополнительный источник
по Курсам (`Q-2`), но до этой досъёмки не снятый (находка **04-7**).

По объёму материала `01_Social` на порядок богаче обоих узлов `04_Brand`:
там по одному баннеру Курсов на узел (2 баннера Курсов всего в `04_Brand`,
считая оба конкурирующих кандидата), здесь — десятки креативов на трёх
страницах. Точное число не подсчитано структурно (`get_metadata` по слоям
не вызывался, оценка — по видимым карточкам на скриншоте страницы):

- `14677:12013` — раскадровка соцсети: группа «неанимированные креативы»
  (1 баннер), группа «креативы активной недели» (около 10 квадратных
  карточек разных размеров) и группа «креативы когда продлили запись»
  (около 20 карточек и превью, включая финальный ряд из 4 крупных
  квадратных карточек с призывом «Забирайте записи воркшопов про ИИ»);
  дополнительно вынесены четыре отдельные 3D-иконки (звезда, стопка кубов,
  ладони, геометрическая фигура) — те же элементы, что использованы внутри
  карточек;
- `13228:414` — 4 горизонтальных рекламных баннера (плюс их превью-миниатюры
  рядом с каждым) и 2 меньших квадратных баннера снизу;
- `12926:192` — 5 горизонтальных рекламных баннеров (плюс превью-миниатюры)
  разных цветовых вариантов.

Итого: **2 верифицированных баннера Курсов на `04_Brand`** (один без
лок-апа, один с лок-апом — и они конфликтуют по цвету, находка 04-6) против
**десятков креативов на трёх страницах `01_Social`**, на каждом из которых
лок-ап «Хабр Курсы» виден отчётливо. Это самый объёмный корпус материала по
Курсам во всём аудите, но он не может закрыть `Q-5` сам по себе: он добавляет
**третий**, отдельный кандидат на палитру, а не подтверждает ни один из двух
уже описанных.

## Цвет (качественно, без literal-значений)

Все три страницы держатся в одном диапазоне, визуально согласованном между
собой и отличном от обоих кандидатов `04_Brand`:

- основной диапазон — **ярко-синий → голубой → сине-фиолетовый градиент**;
  на части баннеров `12926:192` встречается более выраженный фиолетовый фон
  (один баннер) и светлый лавандовый фон (два баннера на `13228:414` и один
  на `12926:192`);
- 3D-иллюстрации — глянцевые, преимущественно **синие и белые** (кубы,
  геометрические фигуры, книги, планшеты, ладони, звезда), без выбивающихся
  ярких вторичных цветов;
- лого/лок-ап «Хабр Курсы» — синий кружок-иконка + тёмный текст, виден на
  каждом креативе и баннере без исключений;
- **неонового кислотного акцента (`#44F91F`, как в `5164:8025`) нигде не
  видно** ни на одной из трёх страниц;
- розово-оранжевой гаммы (`5164:8169`) тоже нет — весь материал холодный,
  в сине-голубой-фиолетовой части спектра, без тёплых тонов.

**Это описание — наблюдение по скриншоту страницы, не измерение.** Точные
hex/rgba фонов, градиентов, лого и текста не сняты — `get_design_context`
по конкретным внутренним узлам (заголовки, фоны отдельных баннеров, стопы
градиентов) в рамках этой досъёмки не вызывался. Извлечение literal-значений —
отдельная, ещё не выполненная задача.

## GAP

- **Точные hex/rgba значения не измерены.** Всё, что выше в разделе «Цвет», —
  качественное описание по скриншоту страницы; `get_design_context` по
  внутренним узлам (фон, градиент, текст, лого) не вызывался ни на одном из
  трёх узлов. Использовать этот файл как источник literal-значений для
  `ui/tokens.css` нельзя — нужен отдельный шаг измерения.
- **Число креативов на каждой странице — оценка по скриншоту**, не
  структурный подсчёт (`get_metadata` не вызывался). Цифры в разделе «Как
  читать этот файл» ориентировочные, для оценки объёма выборки, не для
  точной инвентаризации.
- **Разрешение `Q-5` не продвинуто.** `01_Social` добавляет третий,
  отдельный кандидат на палитру Курсов — не подтверждает и не опровергает
  ни `5164:8025`, ни `5164:8169`. Втроём кандидаты расходятся по цвету
  сильнее, чем было известно на момент review-2. Выбор палитры остаётся за
  владельцем.
- **Внутренняя структура страниц (компонентность, вариативность по
  сегментам аудитории, авторазметка сетки) не инвентаризирована** — снят
  только внешний вид страницы для целей `Q-5`, не полноценный аудит файла
  `01_Social`.
