# Правила сборки

1. Используйте нативный HTML и классы `hds-*`. Базовые стили определяет `ui/reset.css`; CSS-фреймворк не является частью runtime.
2. Значения бренда задаются темой. Компоненты обращаются только к семантическим переменным `--hds-*`.
3. Используйте слои `атом → элемент → организм → блок → страница`. Страница строится из независимых блоков; фиксированный порядок секций не требуется.
4. Сохраняйте нативные `button`, `input`, `label`, `nav`, `header`, `main` и `footer`, видимый focus и подписи полей.
5. Все локальные ресурсы подключайте относительными путями. Единственное внешнее исключение — Inter из Google Fonts. Не используйте обязательные `fetch`, ES modules, npm-runtime или localhost.
6. Диапазоны: 320–479, 480–767, 768–991, 992–1279, 1280–1439 и Large 1440+. Внутри диапазонов сетка резиновая; на Large контейнер фиксирован на 1440 px, фон продолжает расти.
7. `snapshot` описывает Webflow-источник, `normative` — контракт пакета, `assumption` — решение первого среза, которое разрешено пересматривать.

Машиночитаемая версия: [rules.json](../machine/rules.json).
