# Переход с прежнего пакета

Публичный путь `landings/` сохранён, но внутренний API пересобран. Старые demo-классы и файлы не совместимы автоматически с новым набором.

- Начальная точка CSS: `ui/hds.css`.
- Тема: `data-theme="company"` на `html`.
- Публичные классы нового слоя имеют префикс `hds-`.
- Полные примеры: `examples/pages/*/index.html` (11 русских реконструкций).
- Таксономия каталога: атомы → элементы → организмы → блоки → страницы.
- Автономная витрина: `viewer/index.html`.

Прежняя версия находится в локальном архиве `archive/landings/v0.1`. Папка `archive/` не публикуется; восстановление возможно простым копированием нужных файлов из архива.
