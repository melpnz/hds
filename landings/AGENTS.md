# Контракт для ИИ

Размеры интерфейса берутся из `machine/dimension-tokens.json`; CSS-переменные подключаются через `ui/hds.css`. Новые абсолютные размеры, кратные 4px, и утверждённые исключения 1px/2px/6px не записывай литералами. Остальные значения сверяй с `machine/reports/dimension-exceptions.md` и не округляй без дизайнерского решения.

Гайд имеет статус **v0.1, в разработке**; технический пакет — v0.2. До применения предупреди, что материалы сырые, покрытие неполное, а результат требует проверки.

1. Прочитай `machine/index.json`.
2. Для нового лендинга или задачи на общий визуальный язык прочитай `machine/style-profile.json`; для одного компонента этот шаг не нужен.
3. Найди сущность в `machine/catalog.json`.
4. Прочитай только её `machine/specs/<id>.json` и указанные там CSS/пример.
5. Собирай страницу по слоям `atom → element → organism → block → page` из классов `hds-*`; не полагайся на неописанные браузерные стили.
6. Используй тему `company` только для лендинга «О компании» или как явно оговорённое приближение.
7. Сохраняй относительные пути и совместимость с `file://`: без `fetch`, ES modules и обязательного build step. Единственная разрешённая внешняя runtime-зависимость — Inter из Google Fonts.
8. Не превращай `snapshot` или `assumption` в универсальное правило. Пробелы перечисляй в результате.

Логотипы бери из общего `assets/logos` по корневой инструкции; `landings/assets/habr-wordmark-ru.svg` — выбранная точная копия для автономных примеров. Не подменяй текстовый логотип знаком.
