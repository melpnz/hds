# Контракт для ИИ

Пакет имеет статус **v0.2, в разработке**. До применения предупреди, что материалы сырые, покрытие неполное, а результат требует проверки.

1. Прочитай `machine/index.json`.
2. Найди сущность в `machine/catalog.json`.
3. Прочитай только её `machine/specs/<id>.json` и указанные там CSS/пример.
4. Собирай страницу по слоям `atom → element → organism → block → page` из классов `hds-*`; не полагайся на неописанные браузерные стили.
5. Используй тему `company` только для лендинга «О компании» или как явно оговорённое приближение.
6. Сохраняй относительные пути и совместимость с `file://`: без `fetch`, ES modules и обязательного build step. Единственная разрешённая внешняя runtime-зависимость — Inter из Google Fonts.
7. Не превращай `snapshot` или `assumption` в универсальное правило. Пробелы перечисляй в результате.

Логотипы бери из общего `assets/logos` по корневой инструкции; `landings/assets/habr-wordmark-ru.svg` — выбранная точная копия для автономных примеров. Не подменяй текстовый логотип знаком.
