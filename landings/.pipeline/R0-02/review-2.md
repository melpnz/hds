### R2-1 · major · восьмая протечка слоя: `--core-glow-inset`

`fix-1.md` (закрытие 02-1, разделы «Весь слой ядра тем же вопросом») пишет:
«Проверил каждый `@snapshot` в слое ядра... Больше протечек чужого фирменного
цвета в ядре нет» — и перечисляет шесть кандидатов как «нейтральные подложки,
серые и белые»: `--core-bg-surface`, `--core-bg-field`, `--core-text-secondary`,
`--core-glass-*`, `--core-shadow-hard`, `--core-glow-inset`.

Это неверно для последнего из списка. Узел-источник:

```
/* ui/tokens.css:259-260 */
/* @snapshot 02_Landings 18085:3890 — внутренняя подсветка, 6 карточек */
--core-glow-inset: inset 4px 4px 14.4px 10px rgba(89, 89, 248, 0.25);
```

`.pipeline/inventory.json`, узел `18085:3890`: `"product": "habr"`.
`evidence/source/figma/18085-3890.md:1`: «`18085:3890` — «Сильный
медицинский бренд», **Хабр** × НаПоправку». Это тот же узел, откуда
`review-1.md`/`fix-1.md` в других находках (02-6, 02-7) брали evidence, —
значит его принадлежность продукту не была скрыта, её просто не сверили
с цветом.

`rgba(89, 89, 248)` — не нейтральный серый: HSL ≈ (240°, 89 %, 66 %),
насыщенный сине-фиолетовый. Проверено в браузере через живую витрину
(`showcase/blocks.html`, слой 1 «Ядро», плитка «внутренняя подсветка»)
и `getComputedStyle` по шести комбинациям тема×продукт:

```
dark/habr    --core-glow-inset: inset 4px 4px 14.4px 10px rgba(89, 89, 248, 0.25)
dark/career  --core-glow-inset: inset 4px 4px 14.4px 10px rgba(89, 89, 248, 0.25)
dark/courses --core-glow-inset: inset 4px 4px 14.4px 10px rgba(89, 89, 248, 0.25)
light/*      --core-glow-inset: inset 4px 4px 14.4px 10px rgba(89, 89, 248, 0.12)
```

Значение **не меняется по продукту вовсе** (только альфа по теме) — то есть
Habr-специфичный цвет одного узла красит Карьеру и Курсы наравне с Хабром,
в обход собственного принципа пакета, сформулированного в `GUIDE.md:415`:
«цветом различаются продукты, а концепции — приёмом». Ровно это
и было основанием находки 02-1 для `--core-glow-hero`.

Применяется без привязки к продукту:

```css
/* ui/blocks/primitives.css:474 */
.card-glow { box-shadow: var(--core-glow-inset); }
```

и `blocks/card.md:156` даёт пример `<article class="card card-r20
card-glow">` как обычный, продукто-независимый модификатор карточки.

Скриншот витрины (сделан этим ревью, `showcase/blocks.html`, тёмная тема,
слой «Ядро», 1400 px) визуально подтверждает: плитка `--core-glow-inset`
показывает отчётливо синий/фиолетовый блик, а не серый — рядом с шестью
действительно нейтральными плитками того же слоя (`--core-bg-page`,
`--core-bg-surface`, `--core-text-secondary`, `--core-shadow-hard` и т.д.),
что и создаёт визуальный контраст, замеченный при чтении.

**Что не так с выводом `fix-1.md`.** Разбор «весь слой ядра тем же вопросом»
проверил только группу из шести названных кандидатов и не включил
`--core-glow-inset` в число «похожих формально» кандидатов, хотя именно он —
цветной, не нейтральный, и с покрытием 1/18. Формулировка «протечек больше
нет» в отчёте fix была утверждением без полной проверки: она не сопровождалась
числовым порогом хроматичности (S, HSL) ни для одного из шести проверенных
значений, и потому пропуск седьмого не был виден по тексту отчёта.

Родственная, более слабая находка — R2-4 (`--core-text-muted`).

### R2-4 · minor · `--core-text-muted` — тот же вопрос, что R2-1, слабее

```css
/* ui/tokens.css:252-253 */
/* @snapshot 04_Brand 5151:7009 — приглушённый уровень альфой */
--core-text-muted: rgba(219, 233, 240, 0.6);
```

Источник — доска «Неоновый БУМ», продукт Хабр (`.audits/…figma-brand.md:243`,
таблица «Неоновый БУМ (Хабр)», строка «Приглушённый текст»). Значение не
серое: R=219, G=233, B=240 → HSL ≈ (200°, 41 %, 90 %) — заметный холодный
(голубой) оттенок, а не нейтральный, и хуже: 200° — это оттенок в семье
акцента самого Хабра (`--product-accent: #06D0EF` ≈ 189°). В светлой теме
та же роль даёт `rgba(48, 46, 56, 0.6)` — уже нейтральный тёмно-серый
(`GUIDE.md:831`: «альфа только там, где она альфа и в тёмной» — оговорка
не про оттенок, только про механизм альфы). То есть роль в двух темах не
только меняет светлоту, но и меняет цветовую семью — с холодного-голубого
на нейтральный. Отдельно взятое, это не обязательно ошибка (частый приём:
тёмная тема — холоднее), но в сумме с R2-1 показывает, что вопрос «чей это
цвет» в ядре задан не для всех цветоносных значений, а выборочно.

Не поднимаю до major: контраст эффекта на глаз меньше (это полупрозрачный
текст, не заливка тени), и решение «оттенок в тёмной теме может отличаться
