## 1 (04-7) · major · досъёмка Курсов из `01_Social`

**Что было на fix-2.** Находка перенесена: `guide-fix` работает по строгому
контракту — не ходит на прод и не зовёт Figma MCP за новыми данными
(`.claude/skills/guide-fix/SKILL.md`, раздел «Чего не делать»); `01_Social` —
файл с другим fileKey, чем `04_Brand`. Закрыть находку правкой без нового
обращения к Figma было невозможно по правилам самого скилла.

**Что изменилось для этой итерации.** Данные уже добыты — оркестратор
получил три скриншота через `get_screenshot` вне цикла `guide-fix` и положил
их в пакет (`figma-recheck/social-*.png`, продублированы в
`evidence/source/figma/01_Social/`). Эта итерация не сама ходила в Figma MCP —
она оформляет уже полученный материал, что соответствует duх правила
(«не ходить за новыми скриншотами»), а не букве отдельного технического шага.

**Проверено на месте.**

- Все три PNG открыты и сверены с описанием, которое дал оркестратор:
  `14677-12013.png` — раскадровка соцсети (три группы креативов, ~30+
  карточек суммарно, плюс 4 вынесенные 3D-иконки); `13228-414.png` — 4
  крупных горизонтальных баннера + 2 меньших квадратных; `12926-192.png` —
  5 крупных горизонтальных баннеров. Лок-ап «Хабр Курсы» виден на каждом
  креативе без исключений на всех трёх страницах.
- Цветовой диапазон подтверждён визуально: ярко-синий → голубой →
  сине-фиолетовый градиент на большинстве креативов, один явно фиолетовый
  фон и три лавандовых/светлых фона (по описанию оркестратора, сверено по
  PNG). Неонового акцента (`#44F91F`, как в `5164:8025`) и розово-оранжевой
  гаммы (`5164:8169`) не найдено ни на одном креативе.
- Точные hex/rgba **не сняты** — `get_design_context` по внутренним узлам
  (фон конкретного баннера, стопы градиента, цвет лого) не вызывался ни на
  одном из трёх узлов. Оформлять описание как literal-значения было бы
  подменой наблюдения фактом — вместо этого раздел «Цвет» в
  `01-social-courses.md` явно назван качественным и снабжён GAP.

**Что сделано.**

1. `evidence/source/figma/01-social-courses.md` — сводная заметка по трём
   страницам: таблица источника (file, fileKey, узлы, что снято), оценка
   объёма (десятки креативов против 2 верифицированных баннеров `04_Brand`),
   качественное описание цвета без hex, явный GAP на отсутствие
   literal-измерений и на то, что подсчёт креативов — оценка по скриншоту,
   не структурная инвентаризация `get_metadata`.
2. `ROADMAP.md`, **Q-5** — расширен с двух до **трёх** кандидатов: назван
   каждый источник явно, с числом баннеров (1 / 1 / десятки), с ссылкой на
   новый evidence-файл. Статус остаётся `ОТКРЫТ` — выбор палитры не решается
   за владельца, но теперь видна честная картина по объёму материала на
   каждого кандидата.
3. `ROADMAP.md`, **Q-2** / **B-06** — статус уточнён: досъёмка материала
   выполнена (находка 04-7 больше не «не сделано»), но извлечение точных
   значений остаётся отдельной, не назначенной работой.
4. `.pipeline/inventory.json`, `openQuestions.Q-5` — синхронизирован с
   `ROADMAP.md`: третий кандидат добавлен в вопрос и в список `options`,
   добавлено поле `note` со ссылкой на новый evidence-файл.

**Что осталось непокрытым (честно, не вписано как сделанное).**

- Точные hex/rgba значения фонов, градиентов, лого и текста `01_Social` —
  GAP, зафиксирован в `01-social-courses.md`. Нужен отдельный шаг:
  `get_design_context` по конкретным внутренним узлам каждой страницы.
- Число креативов на каждой странице — оценка по скриншоту, не структурный
  подсчёт. Если точное число понадобится (например, для повторения довода
  «десятки против двух» в BRIEF), нужен `get_metadata`.
- `Q-5` не решён и не должен решаться этим шагом — это вопрос владельцу,
  не находка ревью.
- Значения `--product-*` Курсов в `ui/tokens.css` не менялись и не должны
  меняться до ответа на Q-5 (правило зафиксировано ещё на fix-2, здесь не
  пересматривается).
