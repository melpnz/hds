### 04-1 · minor · снимком помечено отсутствие

```css
/* ui/tokens.css:298 */
/* @snapshot 04_Brand 5141:5033 — Карьера единственная без кислотного акцента, 23/23 */
--product-acid: none;
```

против того же значения у Хабра:

```css
/* ui/tokens.css:283 */
/* @normative без выбранной концепции кислотный декор не включён:
   5149:6443 подтверждает только «Неоновый БУМ», не все лендинги Хабра */
--product-acid: none;
```

Одно и то же `none` в одном и том же слое помечено двумя разными маркерами.
И `@snapshot` тут указывает на **один** узел (`5141:5033` — доска «Карьера
как движение»), тогда как заявление покрывает **23 баннера**: узел
источником такого утверждения быть не может, он его частный случай.

**Само утверждение при этом верно**, проверил:
`.audits/landings-2026-09-08-figma-brand.md:435` — таблица «Разведено
по продукту», строка «Кислотный акцент | `#5DF20D` есть | **нет ни одного**
| `#44F91F` есть | **23/23**». И `:469` — у Карьеры 11 баннеров из 23
(7 + 3 + 1), у Хабра 10, у Курсов 1, плюс один без лок-апа. `GUIDE.md:433-436`
пересказывает это точно: «Покрытие 23/23: у Хабра и Курсов кислотный есть,
у Карьеры нет ни на одном из 11 её баннеров». **23/23 сходится.**

**Что сделать.** Заменить маркер на `@normative` с той же причиной и ссылкой
на аудит §5 (или на `@snapshot 04_Brand` с перечислением всех досок Карьеры),
чтобы одинаковое значение в одном слое не было помечено двумя способами.

### 04-2 · minor · «глубокий» тон Курсов — самый светлый

```css
[data-product="courses"]                     --product-base-deep: #00e0ce;  (:310)
[data-theme="light"][data-product="courses"] --product-base-deep: #003580;  (:375)
```

Переснял: `get_design_context 04_Brand 5164:8025` отдаёт два слоя фона,

```
linear-gradient(180deg, rgba(0,153,204,0) 40%, rgb(0,224,206) 84.045%),
linear-gradient(180deg, rgb(0,53,128) 0%, rgb(0,89,153) 20%, rgb(0,153,204) 56%)
```

— `#00E0CE` это нижний стоп верхнего слоя, самый светлый тон семейства.
Комментарий («низ фонового градиента Курсов») это и говорит; спорно имя.
У Хабра `--product-base-deep` = `#030e71`, у Карьеры = `#35006a` — оба
тёмные и, как я измерил в браузере, **одинаковы в обеих темах**. У Курсов
он в тёмной теме `#00e0ce`, в светлой `#003580`, то есть меняет смысл
на противоположный. Блок, написанный на `var(--product-base-deep)` как
на тёмном тоне, у Курсов в тёмной теме получит бирюзовый.

**Что сделать.** Либо переименовать роль у Курсов (`--product-base-top` /
`--product-base-bottom`), либо поставить `--product-base-deep: #003580`
и в тёмной теме, а `#00E0CE` завести отдельным именем. Это правка имени
и назначения, не значения: оба цвета сняты верно.

### 04-3 · minor · «средний стоп» — на самом деле последний

```css
/* ui/tokens.css:311 */
/* @snapshot 04_Brand 5164:8025 — средний стоп фонового градиента Курсов; … */
--product-accent: #0099cc;
```

В снятом слое стопы идут `#003580 0% → #005999 20% → #0099CC 56%`: средний —
`#005999`, `#0099CC` последний. Средним `#0099CC` становится только
в сводном ряду семейства `#003580 → #0099CC → #00E0CE` (`GUIDE.md:370`),
где он и правда посередине. Значение верное, описание пути к нему — нет.

### 04-4 · note · светлых градиентов у продуктов нет

`--product-gradient`, `--product-gradient-veil` и `--product-ribbon`
объявлены вне тем и в светлой теме наследуют тёмное значение — замерено
в браузере. Формально это слой продукта, то есть объём R0-04, но причина
лежит в контракте тем, который заводит R0-02, поэтому находка заведена
там (`02-3`, major) и здесь не дублируется. При правке трогать оба шага.

### 04-5 · note · светлые акценты без чисел

Светлые пары `--product-accent` — `#0b7f96` (Хабр), `#7a3df5` (Карьера),
`#2456c9` (Курсы) — и светлый кислотный Курсов `#2fbf0f`
(`ui/tokens.css:356`, `:366`, `:376-377`) стоят под общим `@normative`
без чисел контраста. Для Р-6 числа названы поимённо и в маркере,
и в `GUIDE.md` §6; для светлых акцентов, на которых надпись встанет так же,
их нет. Не находка — наблюдение о неровности: там, где счёт есть, он
образцовый.
