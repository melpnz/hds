## Stories

## User Salary Within Range
Зарплата находится внутри рыночного диапазона.

## User Salary At Minimum
Зарплата совпадает с минимальным значением рыночного диапазона.

## User Salary At Maximum
Зарплата совпадает с максимальным значением рыночного диапазона.

## High User Salary
Зарплата пользователя значительно выше рыночного диапазона.

## Low User Salary
Зарплата пользователя ниже рыночного диапазона.

## Hidden User Salary
Пользователь скрыл свою зарплату — маркер с аватаром не показывается.

## Without User Salary
Авторизованный пользователь ещё не передавал данные о зарплате.

## Hidden Values For Guest
Значения скрыты для гостя, над графиком показывается предложение добавить зарплату.

## Update Salary Notice
Прошлая зарплата есть, но данные за текущий период требуется обновить.

## Calculator Access Without Current Salary
Доступ к калькулятору есть, поэтому прошлая зарплата отображается без уведомления.

## Mobile
Отображение обычного состояния на узком экране.
