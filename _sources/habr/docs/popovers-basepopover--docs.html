BasePopover

Низкоуровневый popover-компонент на @floating-ui/vue. Принимает DOM-элемент якоря через root, отдаёт slot props с placement, middlewareData и arrowStyle, а закрывается по клику вне контента и по Escape. Без variant компонент не добавляет собственного визуального оформления.
