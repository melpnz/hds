Pagination

Схема разметки компонента такая: < [(furthestPrev)[ (...) (closestPrev)]] (currentPage) [(closestNext) [(...) (furthestNext)]] > [] - опциональные блоки (...) - буквально многоточие (groupName) - группа страниц, например: furthestPrev - страницы от 1 до responsivePadding closestPrev - страницы от currentPage - responsivePadding до currentPage currentPage - номер текущей страницы
