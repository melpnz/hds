Dialog

Стандартное диалоговое окно с обложкой перед заголовком, заголовком, телом и футером с кнопкой закрытия. Дефолтная кнопка действия появляется только при переданном actionButtonLabel. Меняет представление по устройству: на mobile-only открывается как шторка снизу экрана, на tablet/desktop показывается центрированным блоком поверх оверлея.

Disabled Action

disabled блокирует только дефолтную кнопку действия. Диалог по-прежнему можно закрыть кнопкой «Закрыть», оверлеем или клавишей Escape.

Loading

loading показывает индикатор на дефолтной кнопке действия и не даёт закрыть диалог: кнопка «Закрыть» отключена, а оверлей и клавиша Escape не закрывают модальное окно.
