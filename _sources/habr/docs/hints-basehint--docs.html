BaseHint

Базовая hint-подсказка над BasePopover с activator slot, собственным визуальным оформлением, закрытием по кнопке и опциональным slot link. В базовом сценарии компонент сам открывается по клику на activator, а controlled-режим вынесен в отдельную историю.

Stories

Default

Базовый сценарий без visible: подсказка открывается самим компонентом по клику на activator и закрывается по кнопке, клику вне или по Escape.

With Link

Показывает опциональный slot link, который рендерится под основным текстом подсказки.

Without Arrow

Упрощённый вариант без декоративной стрелки.

Controlled

Если передать visible, видимость живёт во внешнем состоянии. В этой истории activator по-прежнему интерактивен, но уже переключает hint через story-level state.
